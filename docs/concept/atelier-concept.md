# ゲームコンセプト: アトリエ錬金術ゲーム

作成日: 2025-12-21
更新日: 2026-10-27
バージョン: 7.1

> 📝 **v7.1 は v7.0 の骨格（調合主軸・庭→調合→納品の三段）を維持したまま、ローグライクとしての面白さを補強する追加です。** Slay the Spire / Backpack Battles との比較で見えた「相手がいない」「手札の制約が弱い」「組み合わせ空間が狭い」の3課題に対し、**素材の鮮度・需要相場・昇格試験のボス戦化・中間素材・熟練ひらめき**を追加しました。詳細は「7. バージョン変更履歴」の v7.1 を参照。

> ⚠️ **v7.0 は「調合」を主軸に据える再設計です。** v6.0で主役だった「庭のグリッド配置パズル」を降格し、**調合（素材の品質・特性を投入枠で組み合わせる判断）を主戦場**に、庭は「品質・特性を持つ素材を狙って仕込む供給層」に位置づけ直しました。三段構成＝**庭（仕込み）→調合（主戦場）→ギルド納品（決算）**。空間配置パズルは廃止。現行実装（`free-phase-navigation`／依頼・採取システム）とは乖離するため、実装反映には大規模な作り直しが必要です。

## 1. ワンセンテンス・コンセプト

> 【誰が】【何をして】【どんな判断を繰り返し】【どんな感情になるゲームか】

```
錬金術師（プレイヤー）が
庭で品質・特性を持つ素材を仕込み、調合台でその素材を投入枠に組み合わせて
「品質を盛るか、特性（貢献度向き／報酬向き）を宿すか」を毎回やりくりしながら
狙った性格の調合物を作ってギルドに納め、ランクを上げていくことで
「調合を練り上げる手応え」と「貢献度と報酬のトレードオフ」「ランクアップの達成感」を味わうゲーム
```

**短縮版（30秒説明）:**
> 庭で品質・特性つきの素材を育て、調合台で素材を組み合わせて狙った品を作り、ギルドに納めてランクを上げていく錬金術師RPG。主役は「調合」——限られた投入枠で品質を取るか特性を取るかを毎回考える。特性は貢献度向きと報酬向きに分かれ、何を作るかがそのまま戦略になる。

**キャッチコピー:**
> 「育てて、練り上げて、ギルドに納めて、ランクを上げろ。」

### 差別化ポイント

```

Slay the Spire: 「戦闘」→「ギルド貢献」に変換、敵HP→ランクHP

独自要素1: 調合＝投入枠の「品質 vs 特性」の食い合い
  → 限られた枠で、品質を盛るか、枠を割いて特性を宿すかを毎回設計する

  → 素材の段階から性格が分岐。どちらの品を作るかがそのままランク進行 vs 強化投資の選択になる
独自要素3: 庭→調合→納品の三段が別軸の判断で連結
  → 庭＝「どんな質・特性の弾を仕込むか（戦略層）」、調合＝「その弾をどう使い切るか（戦術層）」、
    納品＝「日替わり指定に合わせて貢献度か報酬か決算」。判断が二重化せず、因果でつながる
独自要素4（v7.1）: 熟練ひらめき＋中間素材
  → 使い込んだレシピから、投入した特性の方向に新レシピがひらめく。
    「何を作るか」が「どう育てるか」になり、ラン毎に自分だけの調合体系ができる
```

## 5. ゲームサイクル

### メインループ（調合主軸・三段モデル）

主戦場は調合。庭は「品質・特性を持つ素材を狙って仕込む供給層（戦略層）」、
調合は「その素材を投入枠でどう使い切るかの主戦場（戦術層）」、
ギルド納品は「日替わり指定に合わせた決算」。判断は別軸で連結し、二重化しない。

```
┌──────────────────────────────────────────────────────┐
│                       状況把握                        │
│  ランクHP・本日の指定調合物・素材在庫（鮮度）・       │
│  庭の育成状況・需要相場・レシピの熟練度               │
└──────────────────────────────────────────────────────┘
                        ↓
    ┌──────────────────────────────────────────┐
    │  ① 庭：仕込み層（戦略・数ターン先）        │
    │   ・何の種を植えるか＝どの特性の弾を作るか │
    │     （調合から逆算＝注文生産）             │
    │   ・いつ収穫するか＝品質を確定             │
    │     （Bで抜くか、S狙いで枯死リスクを賭けるか）│
    │   ・収穫時に特性が1つ付く（分散乱数・狙いは絞れる）│
    └──────────────────────────────────────────┘
                        ↓ 品質＋特性を持つ素材
    ┌──────────────────────────────────────────┐
    │  ② 調合：主戦場（戦術・今この手番）★核心   │
    │   ・レシピの投入枠（例4枠）に在庫から素材を選ぶ│
    │   ・品質を盛るか、枠を割いて特性を宿すか   │
    │     （食い合い＝トレードオフ）             │
    │   ・特性は「貢献度向き」/「報酬向き」に二分 │
    │     → 成果物の性格を設計する               │
    │   ・中間素材を作って枠を節約（v7.1）       │
    │   ・調合のたびに熟練度↑→ひらめき（v7.1）  │
    └──────────────────────────────────────────┘
                        ↓ 完成品（品質＋性格）
    ┌──────────────────────────────────────────┐
    │  ③ ギルド納品：決算（自動）                │
    │   ・日替わり指定調合物に合致でボーナス     │
    │   ・貢献度（ランクHPにダメージ）or 報酬     │
    │   ・需要相場で価値が変動（v7.1）           │
    └──────────────────────────────────────────┘
                        ↓
     ランクHP0？ → 昇格試験（別ルールのボス戦）へ！
                        ↓
       （必要なら）ショップで種・レシピ・強化を購入
                        ↓
                    次のターンへ
```

### 庭（仕込み層）の仕組み ※空間配置パズルは廃止

- **何を植えるか**: 手持ちの種から選ぶ（マス配置なし。スロット数だけの制限）
- **収穫タイミング**: 成熟後は放置で品質が上がるが、規定ターン超で**枯死（全損）**。「今Bで抜くか、S狙いで1ターン賭けるか」を毎回判断（手動収穫）
- **特性の仕込み**: 収穫時に特性が1つ乱数で付く。乱数は**分散のみ**（期待値は動かさない）で、種やシナジーで狙いを絞れる
- **成長速度**: 素材の種類ごとに成熟ターン数が異なる（早熟＝薬草、晩成＝希少鉱石 等）
- **注文生産**: 「次に作りたい調合物・指定調合物」から逆算して、必要な特性の素材を狙って植える

### 素材の鮮度（確定仕様 v7.1）

収穫後の素材は時間とともに劣化する。在庫を持ち越せることで「良い素材を溜め込んで後でまとめて使う」が最適になる問題を防ぎ、**「今ある物で今日作る」圧**を毎ターン発生させる（Slay the Spire の手札・Backpack Battles のショップに相当する制約）。

- 収穫後、一定ターンごとに**品質が1段ずつ低下**し、最後は**腐敗（消滅）**する
- 素材ごとに劣化速度が異なる。鉱石など一部は**劣化しない素材**として差を付け、管理の手間を抑える
- **中間素材は劣化しない（または極めて遅い）** → 腐りかけの素材を加工して保存する判断が生まれる
- 庭の「いつ収穫するか」と連動する：早く抜くと鮮度の時計が早く動き出す
- 劣化ターン数はバランス調整で確定する

### 調合（主戦場）の仕組み ★このゲームの核心（確定仕様 v7.0）

- **投入枠 = 4枠**（強化で +1 の余地あり）。在庫から素材を選んで入れる
- 各素材は **品質（D〜S＝スコア1〜5）** ＋ **特性タグ 0〜2個** を持つ
- **品質**: 完成品の品質＝投入素材の平均品質（既存の純粋関数 `calculateQuality` を流用）
- **特性の発現（閾値発現）**: **同じ特性タグを持つ素材を2個以上投入すると、その特性が成果物に宿る**（1個では不発）
- **食い合い**: 特性を宿すには2枠以上を割く → その枠を高品質・無特性素材に使えず品質が下がる。逆に高品質素材で埋めると特性が不発で「凡庸な高品質品」になる → **品質を取るか特性を取るかの択一が毎回発生**
- **特性の二分**: 特性は **貢献度系**（聖・浄・癒＝貢献度+）と **報酬系**（金・華・稀＝報酬+）に大別。ほか補助系（触媒＝品質+1段 等）。成果物の性格を決める
- **成果物の価値**:
  - `貢献度 = 基礎貢献度 × 品質倍率 × 貢献度系特性ボーナス × 指定合致ボーナス × 相場倍率`
  - `報酬   = 基礎報酬   × 品質倍率 × 報酬系特性ボーナス   × 指定合致ボーナス × 相場倍率`
  - 相場倍率は v7.1 で追加（「ギルド貢献の仕組み」の需要相場を参照）
  - 品質倍率は既存 `calculateAverageQualityMultiplier` を流用
- **段階的開示**: Gランクは特性なし（品質だけ）→ E〜で貢献度系/報酬系を解禁 → D〜で種類追加
- **毎ターンの問い**: 「限られた在庫で、この4枠に何を入れて、品質を取るか・どの特性を宿すか」

### 中間素材（確定仕様 v7.1）

納品物ではなく、**別の調合に使うための素材**を作るレシピ。特性を凝縮して、本番の調合で枠を節約できる。

- **効果**: 1枠で同じ特性2個分として数える、品質を落とさず特性を宿せる、2特性を同時に持つ など
- **食い合いとの釣り合い**: 中間素材は4枠の「品質 vs 特性」の食い合いを緩める手段。強すぎて食い合いが消えないよう、**中間素材を作るのにも1回の調合（＝時間）がかかる**ことをコストとする
- **鮮度**: 劣化しない（または極めて遅い）。保存目的の加工という判断を生む
- **入手経路は二本立て**:

| 種類 | 入手 | 効果の範囲 | 役割 |
|------|------|-----------|------|
| 通常の中間素材レシピ | 確実（ショップのレシピ解禁・ランク報酬） | **1特性の凝縮**が基本形（例：聖水＝1枠で聖2個分） | 中間素材の使い方を覚える |
| ひらめき由来の中間素材レシピ | 運と育て方次第 | **通常では作れない上位効果**（例：祝福の金粉＝聖と金を同時に持つ） | 通常の上位を狙う目標 |

### 熟練ひらめき（確定仕様 v7.1）

使い込んだレシピから新しいレシピがひらめく。**「いつひらめくか」は熟練度と運、「何をひらめくか」はプレイヤーの調合内容**で決まる。隠し組み合わせを当てる方式ではないため、データ作りが軽く、周回しても驚きが薄れにくい。

- **熟練度**: レシピごとに調合回数を記録。回数が増えるほどひらめく確率が上がる
- **天井あり（確定）**: 一定回数で必ずひらめく。何回やってもひらめかない体験を構造的に防ぐ
- **調整用のつまみ**（仮置き。必要に応じてつまみを追加する）:

| パラメータ | 仮置き値 |
|-----------|---------|
| 初回確率 | 10% |
| 1回ごとの上昇幅 | +15% |
| 天井 | 5回目で確定 |

  - 目安：1ランク（10〜20分）の中で1〜2回ひらめく頻度
  - ひらめいたら熟練度は0にリセット
- **ひらめく内容の決定**: ひらめいた瞬間の調合に投入した特性の方向で決まる（例：回復薬に聖の素材 → 聖系の派生）。プレイヤーは狙った方向に寄せられるので、作業ではなく「どの方向に育てるか」の判断になる
- **ひらめきの結果は2種類**:
  - **中間素材レシピ**（上表のひらめき由来）
  - **派生の納品用レシピ**（例：上級回復薬）
  - 元のレシピの種類で出るものを分ける（納品用レシピ → 派生品と中間素材の両方／中間素材レシピ → 上位の中間素材）

| 元のレシピ | 投入した特性 | ひらめき（例） |
|---|---|---|
| 回復薬 | 聖 | 聖水（中間素材） |
| 回復薬 | 癒 | 薬草エキス（中間素材）／上級回復薬（派生） |
| 宝飾品 | 金 | 金粉（中間素材） |
| 宝飾品 | 聖＋金 | 祝福の金粉（中間素材・2特性） |

- **解禁**: 特性が解禁される **Eランクから**。上のランクほどひらめきの候補（より強い中間素材・派生）が増える
- **成長軸**: 技量はランクに一本化（別のレベル軸は持たない）
- **持ち越し（確定）**: ひらめいたレシピは**ラン間で持ち越さない**。毎ランの育て方を変えるため
- **図鑑**: 発見したレシピと「どの元レシピ・どの特性からひらめいたか」を記録。次のランで狙いを寄せる手がかりにする。未発見は「？？？」で枠だけ表示し、発見の驚きは残す

### ギルド貢献の仕組み（依頼廃止 → 調合物の直接納品＋日替わり指定）

- 作った調合物はギルドへ自動納品。各調合物は **貢献度**（ランクHP＝敵を削る）と **報酬**（ゴールド＝強化原資）の2つの価値を持つ
- **日替わり指定調合物（疑似依頼）**: ギルドが毎日「求める調合物」を提示。合致で貢献度／報酬にボーナス。これが庭の仕込み目標と調合の短期目標を同時に供給する背骨
- 特性が素材段階から貢献度向き／報酬向きに分岐するため、**「今ランクを削る品を作るか、稼いで強化する品を作るか」が庭の仕込みの時点から先行投資になる**（後から取り返しにくい＝真のトレードオフ）
- 品質（D〜S）が高いほど貢献度・報酬とも増加する
- **需要相場（確定仕様 v7.1）**: 同じ種類の調合物を続けて納品すると価値が下がり、しばらく納めていない品は価値が上がる
  - プレイヤーの行動にギルド側が反応する「相手」の役割を担い、最適な1品の量産を自然に防ぐ
  - 下落は2回目から少しずつ（罰に感じさせない程度）
  - 熟練ひらめきとの緊張：同じレシピを繰り返すとひらめきに近づくが、同じ品の納品は相場を下げる → **「値崩れを覚悟で修行するか、別の品で稼ぐか」**。修行が損すぎないよう下落幅と天井回数をセットで調整する
  - 計算式では `相場倍率` として貢献度・報酬の両方に乗算する

- **制限ターン（確定）**: 各ランクに**残りターン制限を設ける**（未達で降格リスク）。「報酬で稼ぐ余裕があるか、今すぐ貢献度を削るべきか」が毎ランク問われ、トレードオフの一択収束を防ぐ。具体的なターン数はバランス調整で確定する。

### 昇格試験（ボス戦・確定仕様 v7.1）

ランクHPを削り切った後の昇格試験を、通常ターンと**別ルールのボス戦**にする。それまでに組んだ工房（枠・庭・レシピ・ひらめき）を試す「ビルドの答え合わせ」の場。

- **出題例**: 「3ターンで指定の3品を納品」「投入枠3で品質A以上」「特定の特性を2つ同時に宿す」「中間素材を使った品を納めよ」（上位ランク）
- **試験の予告**: ランク開始時に試験の種類を予告する。ランダムすぎて準備が報われない事態を防ぎ、ランク中の仕込み・ひらめきの方向付けの目標にする
- **合格報酬**: 次ランクの要素解禁（特性の種類・ひらめき候補・通常中間素材レシピなど）と結び付け、試験を突破する意味をはっきりさせる
- 試験の具体的な種類・難易度はランクごとにバランス調整で確定する

### 金（報酬）の使い道／工房強化（確定仕様 v7.0）

報酬（ゴールド）は **「効率」を買う投資** に使う。**時間（ターン）は買えない**のが設計の核心。

- **金でターンを延長できない（意図的な除外）**: ターン制限を「動かせない硬い締切」として残すことで、「稼ぐために使ったターンは戻らない」＝**早期の報酬投資は複利で効くが賭けになる**という真のジレンマが立つ。金で締切を緩められると貢献度 vs 報酬のトレードオフが崩れるため、延長は用意しない。
- **恒久投資（ビルド＝ランクをまたいで残る）**:
  - **投入枠 +1**（最高額）: 4枠→5枠。品質と特性を両立しやすくなる、ゲームの土台を変える一手
  - **庭拡張**（高額）: 同時に仕込める素材スロットを増やす → 弾の供給量が上がる
  - **レシピ解禁**（高額）: 作れる調合物・狙える特性の幅を広げる
- **消耗投資（そのターン／その調合で消える）**:
  - **触媒の常備・購入**（中額）: 品質+1段の補助素材を切らさない
  - **種の指名買い**（安価）: 欲しい特性の種をピンポイントで購入し、庭の仕込みを狙い撃ちする
- **価格序列**: `投入枠+1 ≫ 庭拡張 ≒ レシピ解禁 ＞ 触媒 ＞ 種の指名買い`
- **購入タイミングの分離**: 恒久投資は**ランク間の工房強化画面**でまとめて、消耗投資は**ターン中いつでも**。恒久＝腰を据えた大決断、消耗＝その場のリカバリー、と判断の性質を分ける
- **複利ループ**: 早めに恒久投資（枠・庭・レシピ）へ金を回すほど後半の生産効率が上がる。ただし投資に回したターンは貢献度を稼げないため、**「今削るか、投資して後で速く削るか」**が締切に対する賭けになる

### 状況に応じた判断の例

| 状況 | 優先すべき判断 | 理由 |
|------|--------------|------|
| ターン開始時 | 本日の指定調合物を確認 | 何を作るべきかの短期目標 |
| 素材が足りない | 指定から逆算して庭に仕込む | 狙った特性の弾を用意する |
| 収穫可能 | Bで抜くかS狙いで賭けるか判断 | 品質を確定する一手 |
| 調合可能 | 投入枠に品質/特性を配分 | このゲームの核心の判断 |
| ランクを急ぎたい | 貢献度向き特性を宿した品を作る | ランクHPを速く削る |
| 強化したい | 報酬向き特性を宿した品を作る | ゴールドで種・レシピを拡充 |
| 素材が腐りかけ | 今日使い切るか、中間素材に加工して保存 | 鮮度で失う前に価値を確定する |
| 同じ品の相場が下落 | 別の品に切り替えるか、ひらめき狙いで続けるか | 稼ぎと修行のトレードオフ |
| ひらめきが近い | 狙いたい方向の特性を投入する | ひらめく内容を寄せる |
| 試験が近い | 予告された試験内容から逆算して仕込む | ビルドの答え合わせに備える |

### 検証すべき最優先の仮説（プロトタイプ）

> **「素材の品質・特性の組み合わせで成果物が変わることを、プレイヤーは"考えて選ぶ"だけの面白さと感じるか（＝どの素材を入れるか一瞬迷うか）」**

**v7.1 追加の観点**: 同じ素材セットを渡すだけでなく、指定・締切・在庫（鮮度）・相場の状況を何パターンか変えて、**「さっきと違う選択をしたか」**まで観察する。状況によって正解が変わらなければ、組み合わせ空間が狭すぎる兆候。

## 7. バージョン変更履歴

### v7.1 主要変更点（ローグライクとしての補強）

| 要素 | v7.0 | v7.1 |
|------|------|------|
| 在庫 | 持ち越し自由（溜め込みが最適になりがち） | **素材の鮮度**：品質が段階的に低下し腐敗。中間素材・一部素材は劣化しない |
| 納品価値 | 固定的な計算式 | **需要相場**：同じ品の連続納品で下落、休ませた品は上昇 |
| 昇格試験 | ランクHP削り後の通過点 | **別ルールのボス戦**：ランク開始時に予告、合格で要素解禁 |
| 中間素材 | なし | **通常レシピ（1特性凝縮）＋ひらめき由来（上位効果）の二本立て** |
| レシピ獲得 | ショップ・ランク報酬のみ | **＋熟練ひらめき**：熟練度で確率上昇・天井あり、内容は投入特性で決まる |
| 成長軸 | ランク | **ランクに一本化**（技量レベルは持たない） |
| 持ち越し | 未定義 | **レシピは持ち越さない、図鑑に記録のみ** |

### v7.1 の変更理由

Slay the Spire / Backpack Battles と面白さの源泉を比較し、v7.0 の弱点を3つ特定した。

- **相手がいない** → ランクHPは削られるだけで反撃しない。**需要相場**でギルドがプレイヤーの行動に反応し、**昇格試験のボス戦化**で通常と違う問いを突きつける
- **手札の制約が弱い** → 在庫を持ち越せるため適応圧が弱い。**素材の鮮度**で「今ある物で作る」圧を作る
- **組み合わせ空間が狭い** → 4枠・2個発現では最適配分が1つに収束しやすい。**中間素材**で配分の幅を広げ、**熟練ひらめき**でラン毎に違う調合体系が育つようにする
- **作業化の歯止め**：ひらめきの「同じレシピを繰り返す」動機を、需要相場の「同じ品は値崩れ」で相殺し、修行 vs 稼ぎのトレードオフにする
- **周回動機**：レシピを持ち越さず図鑑にだけ残すことで、毎ランの育て方が変わり、図鑑の「？？？」が次のランの目標になる

### 検討したが今回は見送った案（メモ）

- 指定調合物の予告、監査官（ランクごとの癖）、ギルドの反撃、ライバル錬金術師、派閥、耐性と弱点、大口注文、評判コンボ
- 在庫上限、調合台のドロー、1日の調合回数制限、収穫の豊作・不作
- 特性の合成（上位特性）、レシピごとの枠ルール、枠の位置効果、アーティファクトでのルール変更、特性の段階発現
- オリジナルレシピの条件書き込み型・特産品型・枠設計型（ひらめき＋中間素材方向を採用）

### v7.0 主要変更点（調合主軸への転換）

| 要素 | v6.0 | v7.0 |
|------|------|------|
| 主軸 | 庭のグリッド配置パズル | **調合（投入枠での品質 vs 特性の設計）** |
| 庭 | 主役（空間配置＋隣接シナジー） | **供給層に降格（配置パズル廃止、狙い撃ち仕込みは残す）** |
| 調合 | レシピを選ぶだけ | **投入枠に素材を組み合わせる主戦場** |
| 素材 | 品質のみ | **品質＋特性（貢献度向き／報酬向きに二分）** |
| トレードオフ | 調合物の貢献度/報酬（偽ジレンマ懸念） | **特性を素材段階から二分し先行投資化（真のジレンマ）** |
| 短期目標 | なし（依頼廃止で喪失） | **日替わり指定調合物（疑似依頼）で背骨を復活** |
| 判断の核心 | 庭の配置構築 | **調合の投入枠設計（＋庭の仕込み＋納品の決算）** |
| 金の使い道 | 未整理 | **効率を買う投資に限定（時間は買えない）＝恒久/消耗の二層** |

### v7.0 からの変更理由

- **アトリエらしさ**: 「調合」をゲームの主役に据え、名前とテーマに一致させる
- **判断痩せの解消**: 主戦場を調合に置き、投入枠のトレードオフで毎ターンの最適化圧を作る
- **偽ジレンマの構造解決**: 特性を貢献度向き／報酬向きに二分し、庭の仕込み段階からの先行投資にする
- **短期目標の復活**: 日替わり指定調合物で「今日何を作るか」の羅針盤を供給
- **判断の二重化回避**: 庭＝戦略層、調合＝戦術層と時間軸で役割分離
- **資産再利用**: 既存の品質計算（Functional Core）が調合の中核として活きる
- **報酬側の使い道を確立**: 金を「効率を買う投資（枠・庭・レシピ・触媒・種）」に限定し、時間延長を除外することで貢献度 vs 報酬を偽ジレンマ化させない
- **⚠️ 注意**: 現行実装（`free-phase-navigation`／依頼・採取）からは大きく乖離。実装には大規模な作り直しが必要
