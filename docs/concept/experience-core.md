## 1. 中核判断

### プレイヤーの唯一の問い

```
プレイヤーは常に「限られた在庫と投入枠で、品質を取るか、どの特性を宿すか？」を考えている
```

### 判断の詳細

| 項目 | 内容 |
|------|------|
| 判断が発生する場面 | 毎ターン、調合台の投入枠（4枠）に在庫の素材を入れる時 |
| 選択肢の例 | 高品質・無特性の素材で枠を埋める / 枠を2つ割いて特性を宿す / 中間素材で枠を節約する / 腐りかけの素材を先に使う / 相場の高い品を選ぶ / ひらめきを狙って同じレシピを続ける |
| 判断を面白くする要素 | 本日の指定調合物・素材の鮮度・需要相場・熟練度・残りターン・予告された昇格試験によって、同じ在庫でも正解が変わる |

### 状況に応じた判断の例

- **ターン開始時** → 本日の指定調合物と相場を見て、作る品を決める
- **素材が足りない** → 指定や試験の予告から逆算して、庭に狙った特性の種を植える
- **収穫できる** → 品質Bで抜くか、S狙いで1ターン賭けるか決める（早く抜くと鮮度の時計も早く動く）
- **調合できる** → 投入枠に品質と特性をどう配分するか決める（このゲームの核心）
- **素材が腐りかけ** → 今日使い切るか、中間素材に加工して保存する
- **同じ品の相場が下落** → 別の品で稼ぐか、値崩れを覚悟でひらめきを狙うか
- **ひらめきが近い** → 狙いたい方向の特性を投入して、ひらめく内容を寄せる
- **試験が近い** → 予告された試験ルールに合わせて在庫を仕込む

## 2. 判断成立の前提条件

| 条件 | 適合状況 | 具体的な設計 |
|------|---------|-------------|
| 情報が不完全 | [x] | 収穫時の特性は乱数（分散のみ）、品質上昇は確率、ひらめくタイミングは確率、日替わり指定は毎ターン抽選 |
| 選択にコストがある | [x] | 特性を宿すには2枠を割き品質が下がる。中間素材を作るにも1回の調合（＝手番）がかかる。素材は投入で消費され、放置すると腐る |
| 結果がすぐに分からない | [x] | 庭の仕込みは数ターン先に効く。報酬で行う恒久投資は後半に複利で効く。ひらめきは熟練度が溜まるまで分からない |

## 3. 判断→結果→学習ループ

### メインループ

```
状況把握: ランクノルマ・残りターン・本日の指定調合物・素材在庫（鮮度）・
          庭の育成状況・需要相場・レシピの熟練度・予告された昇格試験

判断:
  ① 庭（戦略・数ターン先）: 何を植え、いつ抜くか
  ② 調合（戦術・今この手番）★核心: 投入枠に品質と特性をどう配分するか
     ・中間素材を作って枠を節約するか
     ・ひらめきを狙う方向の特性を投入するか

結果:
  - 完成品をギルドへ自動納品 → 貢献度（ランクノルマを削る） or 報酬（ゴールド）
  - 指定合致でボーナス、相場倍率で価値が変動
  - 熟練度が上がり、ひらめけば新しいレシピが解禁
  - ターン経過で素材が劣化し、相場が回復する
  - 制限ターン到達時にノルマ0 → 予告された昇格試験（別ルールのボス戦）へ

学習:
  - どの特性の素材を仕込むと、調合で品質と特性を両立できるか
  - どのレシピを育てると、どんな中間素材・派生品がひらめくか（図鑑に記録される）
  - 相場と鮮度を見て、いつ何を作るとよいか
```

### ループ詳細

| 項目 | 内容 |
|------|------|
| ループの回転速度 | 1ターン（30秒〜1分） |
| 結果が判明するまでの時間 | 即座（調合・納品）〜数ターン後（庭の収穫、ひらめき）〜ランク終了時（昇格試験） |
| 学習の蓄積方法 | プレイヤースキル（調合の配分・仕込みの読み）＋ラン内の成長（恒久投資・ひらめいたレシピ）＋ラン間の知識（図鑑） |

## 4. リソース設計

### プライマリリソース

| リソース名 | 役割 | 獲得方法 | 消費タイミング |
|-----------|------|---------|---------------|
| 素材（品質＋特性） | 調合の材料 | 庭で収穫・ショップ・中間素材の調合 | 調合で消費。放置すると劣化し、最後は腐敗 |
| 中間素材 | 特性を凝縮した素材（1枠で特性2個分） | 中間素材レシピで調合 | 調合で消費。劣化しない |
| 庭スロット | 素材の供給量 | 初期・恒久投資「庭拡張」 | 植えた種が収穫・枯死するまで占有 |
| 投入枠 | 1回の調合に入れられる素材数（初期4） | 恒久投資「投入枠+1」 | 毎回の調合で配分を決める |
| ゴールド | 投資の原資（効率を買う。時間は買えない） | 報酬向きの調合物を納品 | 恒久投資・消耗投資 |
| ターン | 締切（制限ターン） | 買えない | 毎ターン必ず減る |
| レシピ | 作れる品の幅 | 初期・レシピ解禁・試験の合格報酬・熟練ひらめき | 消費しない（ひらめいたレシピはラン終了で失う） |

### 指標リソース

| 指標名 | 役割 | 増減方法 |
|--------|------|---------|
| **ランクノルマ** | 0にして制限ターンを迎えると昇格試験 | 貢献度向きの調合物の納品で減少 |
| **需要相場** | 同じ品の量産を防ぐ「ギルドの反応」 | 納品で下落、休ませると回復 |
| **熟練度** | ひらめきへの近さ | 調合で上昇、ひらめくと0に戻る |
| **降格回数** | 規定回数でゲームオーバー | 制限ターン到達時のノルマ残存・試験失敗で増加 |

### リソース枯渇時の緊張感

| 状況 | 何が起きるか | プレイヤーの感情 | リカバリー手段 |
|------|------------|-----------------|---------------|
| 素材不足 | 狙った特性を宿せない | 仕込みの読みの重要性を実感 | 庭に狙った種を植える・種を指名買い |
| 素材が腐りかけ | 価値を失う | 「今使うか、加工するか」の焦り | 今日使い切る・中間素材に加工する |
| 相場の下落 | 同じ品では稼げない | 量産ではなく切り替えを迫られる | 別のレシピで納品する |
| ゴールド不足 | 投資できない | 報酬向きの品の重要性を実感 | 報酬向き特性を宿して納品する |
| 残りターン不足 | 降格が近づく | 締切の緊張 | 貢献度向きの品に集中する |

### リソースフロー図

```
┌──────────────┐   品質＋特性    ┌──────────────────┐
│ 庭（仕込み） │ ─────────────→ │ 在庫（鮮度で劣化）│ ←── ショップ（種・触媒）
└──────────────┘                └──────────────────┘
                                   │        ↑
                                   │        │ 中間素材（劣化しない）
                                   ↓        │
                              ┌──────────────────┐
                              │ 調合（投入枠）★  │ ─→ 熟練度 → ひらめき → 新レシピ
                              └──────────────────┘
                                   │ 完成品
                                   ↓
                              ┌──────────────────┐
                              │ ギルド納品（自動）│ ←── 指定合致ボーナス × 相場倍率
                              └──────────────────┘
                               │貢献度        │報酬
                               ↓              ↓
                         ランクノルマ減少   ゴールド → 工房強化（投入枠・庭・レシピ）
                               │
                               ↓
                 ノルマ0＋制限ターン → 予告された昇格試験 → 合格報酬 → 次ランク
```

## 5. 失敗設計

### 主な失敗パターン

| 失敗パターン | 原因の明確さ | 学習につながるか | 備考 |
|-------------|-------------|-----------------|------|
| 制限ターン到達時にノルマが残る（降格） | [x] | [x] | 「報酬に寄せすぎた」→「貢献度向きの品を早めに作る」 |
| 昇格試験に失敗する | [x] | [x] | 「予告を見ずに仕込んだ」→「試験ルールから逆算して在庫を用意する」 |
| 素材を腐らせる | [x] | [x] | 「溜め込みすぎた」→「収穫のタイミングと使い道をそろえる」 |
| 相場が下がって稼げない | [x] | [x] | 「同じ品を量産した」→「品を切り替える」 |
| 特性が発現しない | [x] | [x] | 「同じ特性を2個そろえられなかった」→「庭の仕込みや中間素材で特性を確保する」 |
| 庭の株が枯死する | [x] | [x] | 「S狙いで欲張った」→「枯死猶予を見て抜く」 |

### 失敗からのリカバリー

- **リトライまでの時間**: 降格しても同じランクに留まり、在庫・庭・ゴールド・恒久投資を引き継いで再挑戦できる。ランクごとに10〜20分
- **失敗時に得られる情報**: 納品結果（相場・指定合致）、試験の達成状況、図鑑の発見状況
- **「次はこうしよう」と思えるか**: [x] 明確な改善点が見える
  - 「次は聖の素材を2つ確保してから試験に入ろう」
  - 「回復薬に癒を入れ続けたら上級回復薬がひらめくかもしれない」（図鑑の「？？？」が目標になる）
  - 「早めに投入枠+1を買えば後半が楽になる」

## 6. 面白さの言語化

### 最終定義

```
このゲームは
「庭で品質・特性つきの素材を仕込み、限られた投入枠で品質を取るか特性を宿すかを毎回設計し、
　鮮度と相場に追われながら狙った品をギルドに納め、
　使い込んだレシピから自分だけの調合体系をひらめかせてランクを上げていくことが楽しい」
```

### 完成チェック

- [x] 中核判断が明確に含まれている（投入枠での品質 vs 特性）
- [x] 制約（リソース）が含まれている（投入枠・鮮度・相場・締切）
- [x] 動詞（行動）が含まれている（仕込み、設計し、納め、ひらめかせて）
- [x] 達成感が含まれている（ランクアップ・ひらめき）
- [x] 一文で読んで面白そうと思えるか

## 7. 補足事項

### 設計上の注意点

- **主戦場＝調合** → 庭は供給（戦略層）、納品は自動決算。思考を調合に集中させる
- **ギルドランク＝審査基準** → ノルマを納品でこなす。需要相場がプレイヤーの行動に反応する「相手」
- **昇格試験＝ビルドの答え合わせ** → ランク開始時に予告され、別ルールで工房の完成度を試す
- **素材＝鮮度のある手札** → 溜め込みではなく「今ある物で今日作る」
- **成長＝ランクに一本化** → 技量レベルは持たない。ひらめいたレシピは持ち越さず図鑑に残す

### 今後の検討事項

- 鮮度の劣化ターン数、相場の下落・回復幅、ひらめき確率（[`balance-design.md`](../design/atelier-alchemy-core/balance-design.md)「v7.1追加パラメータ」）
- 中間素材・ひらめき候補の対応表
- ランクごとの試験ルールと合格報酬
- 1画面プロトタイプで「調合で一瞬迷うか」「状況を変えると違う選択をするか」を検証する
