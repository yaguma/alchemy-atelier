# 工房強化・ショップ画面 詳細設計

作成日: 2026-08-04
準拠要件: [`../../../../spec/atelier-alchemy-core/requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) §3「工房強化・ショップ」、§4「ショップ／工房強化」

## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-004 |
| 親画面 | 庭画面/調合画面（消耗投資はターン中いつでもオーバーレイ表示）、昇格試験成功時（恒久投資は強制表示） |
| 子画面 | なし |

要件定義書L81・L133-137に基づき、**恒久投資（投入枠+1／庭拡張／レシピ解禁）はランク間の工房強化画面でのみ購入可能**、**消耗投資（触媒／種の指名買い）はターン中いつでも購入可能**という2つのアクセス経路が存在する。本画面はこの2モードを内包する。

## ワイヤーフレーム

```
┌─────────────────────────────────────────────┐
│  工房強化・ショップ         所持ゴールド: {G} │
├─────────────────────────────────────────────┤
│ [恒久投資]タブ（ランク間のみ活性化）           │
│  投入枠+1        価格{最高額}  [購入する]      │
│  庭拡張          価格{高額}    [購入する]      │
│  レシピ解禁: {name} 価格{高額} [購入する]      │
├─────────────────────────────────────────────┤
│ [消耗投資]タブ（ターン中いつでも活性化）       │
│  触媒            価格{中額}    [購入する]      │
│  種の指名買い: {name} 価格{安価} [購入する]    │
├─────────────────────────────────────────────┤
│                 [閉じる]                       │
└─────────────────────────────────────────────┘
```

🟡 タブ2分割のレイアウトは要件定義書§4「恒久投資」「消耗投資」の2区分をそのままUI化した本文書での提案。

## UI要素

| 要素ID | 種類 | 説明 | 状態 |
|--------|------|------|------|
| tab-permanent | タブ | 恒久投資一覧を表示。**ランク間の工房強化画面遷移時のみ選択可能**（要件定義書L81） | 活性/非活性（通常ターン中は非活性） |
| tab-consumable | タブ | 消耗投資一覧を表示。ターン中いつでも活性 | 常時活性 |
| item-{upgrade_id} | ショップアイテム行 | 名称・価格・購入ボタンを持つ | 購入可能/購入不可（ゴールド不足） |
| btn-purchase-{upgrade_id} | プライマリボタン | 購入する。`PurchaseValidator.can_purchase`が偽の場合は無効化（🔵要件定義書L83/L136） | 有効/無効 |
| txt-gold | テキスト | 現在の所持ゴールド | - |
| btn-close | セカンダリボタン | 画面を閉じる。恒久投資強制表示時も含め常に「閉じる/次へ」として機能する（🔵購入任意のため、閉じる操作自体は常に許可される） | 常時表示 |

## 状態遷移

### 通常アクセス状態（庭/調合画面からのオーバーレイ）

`tab-permanent`は非活性表示（要件定義書L81の制約をUIで強制）。`tab-consumable`のみ操作可能。

### 昇格直後の強制表示状態

昇格試験成功直後は本画面が強制的に開き、`tab-permanent`が活性化する。閉じる操作はプレイヤーの任意（恒久投資を購入しなくても次に進める。🔵2026-08-04ヒアリングで「購入は任意」と確定、要件定義書§3「工房強化・ショップ」参照）。

### 購入不可状態

`txt-gold` < 対象価格の場合、該当行の購入ボタンが無効化され、価格テキストが警告色になる（🟡TBD）。
