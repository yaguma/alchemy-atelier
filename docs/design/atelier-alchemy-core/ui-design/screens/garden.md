## UI要素

| 要素ID | 種類 | 説明 | 状態 |
|--------|------|------|------|
| slot-{n} | 庭スロット表示 | 空き/生育中/収穫可能/枯死警告の4状態を視覚的に区別する | 空き/生育中/収穫可能/枯死警告 |
| btn-plant-{seed_id} | ボタン | 手持ちの種から選んで空きスロットに植える | 有効（空きスロットあり）/無効（スロット満杯） |
| btn-harvest-{slot_id} | ボタン | 収穫可能なスロットを収穫する | 収穫可能なスロットにのみ表示 |
| btn-wait-{slot_id} | ボタン（任意、🟡） | 収穫せず待機してS狙いする意思表示。実際は「何もしない」と同義だが、UI上は「待つ」ことを明示する導線として提案 | 収穫可能な状態でのみ表示 |
| txt-daily-order | テキスト | 本日の指定調合物の条件を表示 | - |
| btn-shop | ボタン | 工房強化・ショップ画面へ遷移（種の指名買い含む） | 常時有効 |
| btn-end-turn | プライマリボタン | ターンを終了する。押下すると`GameState.end_turn()`が呼ばれ、庭の生育進行・枯死判定・日替わり指定調合物の再抽選・制限ターン判定が一括で実行される（🔴2026-08-06追加、実装レディネス監査対応。旧版は要件定義書§3の「ターンを終了する」操作に対応するUI要素がどの画面にも存在しなかった） | 常時有効 |

## 状態遷移

### 初期状態

Gランク開始時は庭スロットがすべて空き、手持ちの種は初期セット（🟡TBD、要件定義書に初期所持種の規定なし）。

### 生育中状態

各スロットは`成熟までの残りターン数`をアイコン等で表示する（🟡TBD、具体的な表現は実装時）。

### 収穫可能状態

成熟したスロットは「収穫する」ボタンが有効になり、同時に「待つとS狙いできるが枯死リスクがある」旨の警告表示を出す（コンセプト文書§5「庭（仕込み層）の仕組み」参照。🔵2026-08-05修正: 旧版は誤って「要件定義書L204」からの引用としていたが、この文言の実体はコンセプト文書側にありrequirements.mdには存在しない）。枯死猶予ターンに近づくほど警告を強める（🟡TBD、UI強度の段階分け）。

### 枯死警告状態

枯死猶予ターンの残り1ターンなど、閾値に近づいたら赤系の強い警告色に切り替える（要件定義書§4「枯死（全損）」）。

### エラー状態

- スロット満杯時に植えようとした場合: 「庭スロットに空きがありません」のトースト表示（🟡TBD、文言は仮）

## イベント

| イベント名 | トリガー | 処理内容 |
|-----------|----------|----------|
| OnSeedPlanted | 種植えボタン押下 | `GameState.plant_seed(seed_id)`呼び出し、`Planting`で判定 |
| OnHarvested | 収穫ボタン押下 | `GameState.harvest(plant_id)`呼び出し、`Harvest.harvest`で品質・特性確定 |
| OnPlantWithered | ターン終了時（`Harvest.resolve_withering`が枯死株を検出） | 🔴2026-08-05追加、PRレビューCritical#11対応。該当スロットを自動解放し、枯死通知（トースト等）を表示する。プレイヤーが収穫操作をしなくても発火する |
| OnTurnEnded | 「ターンを終了する」押下 | `GameState.end_turn()`を呼び出す（🔴2026-08-06追加）。[`../dataflow.md`](../dataflow.md) の「庭の生育進行→枯死判定→指定調合物再抽選→制限ターン判定」の一連の処理をこの1回の呼び出しで実行する |
| OnShopOpened | ショップボタン押下 | 工房強化・ショップ画面をオーバーレイ表示 |
