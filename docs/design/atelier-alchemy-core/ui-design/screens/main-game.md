## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-001 |
| 親画面 | BootScene / 工房強化画面 |
| 子画面 | 昇格試験画面 / ゲーム終了画面 |

🔵 ターンループの主画面。上部HUD（常時表示）＋中央のフェーズパネル（庭/調合/納品を切替）＋下部の在庫・ターン操作で構成。

## 状態遷移

### 初期状態（ランク開始）
- 🔵 HP満タン・残ターン設定・在庫空・庭空（Gランクは特性封印）。庭パネルを初期表示。

### 調合プレビュー状態
- 🔵 投入枠に素材を置くと品質・発現特性がリアルタイムでプレビュー更新。特性は同一タグ2個以上で「発現」表示。

### 調合実行不可状態
- 🔵 投入枠が0個のとき btn-craft を無効化。

### ゴールド不足状態
- 🔵 価格未満のとき購入ボタンを無効化（庭の種指名買い・触媒・工房強化すべて）。

### 収穫判断状態
- 🔵 成熟スロットは「今Bで抜くか、S狙いで賭けるか」。枯死猶予が近いスロットは警告表示。

## アニメーション

| トリガー | アニメーション | 時間 | イージング |
|----------|---------------|------|-----------|
| フェーズタブ切替 | クロスフェード | 0.2s | ease-in-out |
| 納品時HP減少 | バー減少＋ダメージ数値 | 0.4s | ease-out |
| ゴールド獲得 | カウントアップ | 0.3s | ease-out |
| 指定合致 | ボーナス演出（★） | 0.5s | ease-out |
| 収穫 | 素材が在庫へ飛ぶ | 0.3s | ease-out |

> 🔵 ④フィードバック（貢献度ダメージ演出・報酬表示・指定合致ボーナス・HPバー変化）は [`requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) 1章④に対応。

## イベント

| イベント名 | トリガー | 処理内容 |
|-----------|----------|----------|
| OnMaterialPlaced | 投入枠へ配置 | 品質/特性プレビュー更新 🔵 |
| OnCraftClicked | btn-craft押下 | 調合実行→自動納品→HUD更新 🔵 |
| OnPlantClicked | btn-plant押下 | 種を庭スロットへ植付 🔵 |
| OnHarvestClicked | btn-harvest押下 | 収穫（品質確定＋特性付与）🔵 |
| OnBuySeed/Catalyst | 購入ボタン押下 | ゴールド消費→在庫追加 🔵 |
| OnEndTurnClicked | btn-end-turn押下 | 庭生育進行→制限ターン判定 🔵 |

## アクセシビリティ

- [ ] 特性系統（貢献度系/報酬系/補助系）を色＋アイコン＋ラベルで区別
- [ ] キーボードで投入枠・在庫を選択操作可能
