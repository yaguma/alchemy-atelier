# ギルド納品画面 詳細設計

作成日: 2026-08-04
準拠要件: [`../../../../spec/atelier-alchemy-core/requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) §3「ギルド納品」

## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-003 |
| 親画面 | 調合画面（調合実行時に自動遷移/オーバーレイ表示） |
| 子画面 | なし（庭画面へ戻る） |

要件定義書§3「ギルド納品」の「プレイヤー操作なし（自動決算）。結果の確認のみ」に基づき、**本画面にプレイヤーが能動的に操作するUI要素は存在しない**。演出を見せて自動的に（または「閉じる」押下で）庭画面へ戻る結果表示画面である。

## ワイヤーフレーム

```
┌─────────────────────────────────────────────┐
│              ギルド納品結果                   │
├─────────────────────────────────────────────┤
│  完成品: {調合物名}  品質{score}               │
│  発現特性: [聖][金]                            │
│  本日の指定調合物に  ✓合致（ボーナス+{n}%）    │
├─────────────────────────────────────────────┤
│  貢献度 +{contribution}  → ランクノルマバー減少演出│
│  報酬   +{reward} G                            │
├─────────────────────────────────────────────┤
│                [閉じる/続ける]                 │
└─────────────────────────────────────────────┘
```

🟡 レイアウトは要件定義書§1「④フィードバック」（貢献度反映演出、報酬獲得表示、指定合致ボーナス表示、ランクノルマバーの変化）を画面として組み立てた本文書での提案。

## UI要素

| 要素ID | 種類 | 説明 | 状態 |
|--------|------|------|------|
| txt-product-name | テキスト | 完成した調合物名 | - |
| txt-quality | テキスト | 完成品の品質 | - |
| icon-trait-{tag} | アイコン | 発現した特性タグ一覧 | - |
| txt-order-match | テキスト | 本日の指定調合物への合致有無とボーナス率 | 合致/不合致 |
| bar-rank-quota | ランクノルマバー | 減少アニメーションで貢献度反映を可視化 | - |
| txt-reward | テキスト | 獲得ゴールド | - |
| btn-continue | プライマリボタン | 結果を確認し庭画面へ戻る（一定時間後の自動遷移でも可、🟡TBD） | 常時有効 |

## 状態遷移

### 結果表示状態（単一状態）

本画面はプレイヤー操作を伴わないため、状態遷移は「表示→確認→閉じる」の一本道のみ。指定調合物に合致した場合のみ`txt-order-match`の表示がボーナス表示付きに変化する。

### ランククリア到達時の分岐

このタイミングで`RankQuotaResolver.is_rank_cleared`が真になった場合でも、本画面の「続ける」操作後は通常どおり庭画面へ戻る。具体的な分岐条件は要件定義書§2「勝敗条件」の「制限ターン到達時点でランクノルマが0なら昇格試験」であり、**ノルマ到達時点では即座に昇格試験へは移行しない**（制限ターンの到達が別条件として必要）。ランクノルマが先に0になった後の残りターンは、報酬（ゴールド）を稼ぐ意図的な早期クリアボーナス期間として通常どおりプレイを継続できる（要件定義書§2参照）。この解釈は[`dataflow.md`](../dataflow.md) の全体フロー図と一致する（🔵）。

## エラー状態（🔴2026-08-05追加、PRレビューWarning対応）

- 通常の納品結果表示にエラーケースは存在しない（自動決算のため入力検証の余地がない）。強いて挙げるなら、`DeliveryResolver.matches_order`に不正な`condition_type`が渡された場合は`false`扱いとし、合致なしの通常表示にフォールバックする（[`../core-systems.md`](../core-systems.md) GuildSystem節参照）
