# 昇格試験画面 詳細設計

準拠要件: [`../../../../spec/atelier-alchemy-core/requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md)（2章・7章）

> **信頼性レベル凡例**: 🔵 要件準拠 ／ 🟡 妥当な推測 ／ 🔴 新規推測

## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-003 |
| 親画面 | メインゲーム画面（制限ターン到達 かつ HP=0） |
| 子画面 | 工房強化画面（成功）/ メインゲーム画面（失敗＝降格）/ ゲーム終了画面（Sクリア） |

> 🟡 **本画面は TBD（別途設計が必要）。** 昇格試験は通常ターンループとは別の**一発勝負の特殊局面（ボス戦的な専用画面・専用ルール）**として実装する（[`requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) 2章）。具体的なルール・演出・敗北条件は本設計のスコープ外。

## 確定している境界仕様（🔵）

- 🔵 制限ターン内にランクHPを0にできた場合のみ、通常ループから自動でこの局面へ移行する。
- 🔵 成功 → 次ランクへ昇格し、工房強化画面（恒久投資）へ。
- 🔵 失敗 → 降格（同一ランクに留まって再挑戦）。同ランクでの降格回数が加算され、規定回数（仮3回）到達でゲームオーバー。
- 🔵 Sランクの試験成功でゲームクリア。

## インターフェース境界（本設計で確定・[`../interfaces.gd`](../interfaces.gd) と対応）

| 項目 | 内容 |
|------|------|
| 入力 | 現在ランク・プレイヤー状態（在庫・恒久投資） 🔵 |
| 出力 | `ExamResult { success: bool }` 🟡 |
| 成功時 | `RankSystem.next_rank` → 工房強化画面（Sなら game_cleared）🔵 |
| 失敗時 | 降格処理（降格回数+1）→ 上限判定 → メインゲーム or ゲームオーバー 🔵 |
