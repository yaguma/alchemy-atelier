# 工房強化画面 詳細設計

準拠要件: [`../../../../spec/atelier-alchemy-core/requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md)（3章・4章）

> **信頼性レベル凡例**: 🔵 要件準拠 ／ 🟡 妥当な推測 ／ 🔴 新規推測

## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-002 |
| 親画面 | 昇格試験画面（成功時） |
| 子画面 | メインゲーム画面（次ランク） |

🔵 昇格試験成功後、次ランク開始前に表示。**恒久投資（ランクをまたいで残る）**の購入専用画面。消耗投資（種・触媒）はここではなくメインゲーム画面で行う。

## UI要素

| 要素ID | 種類 | 説明 | 状態 |
|--------|------|------|------|
| ws-gold | テキスト | 所持ゴールド 🔵 | 変動 |
| ws-next-rank | テキスト | 次に挑むランク 🟡 | - |
| card-slot-upgrade | カード | 投入枠+1（最高額・4→5枠）🔵 | 購入可/不可/購入済 |
| card-garden-expand | カード | 庭拡張（高額・庭スロット+）🔵 | 購入可/不可 |
| card-recipe-unlock | カード | レシピ解禁（高額・作れる調合物拡張）🔵 | 購入可/不可 |
| btn-purchase | プライマリボタン | 各投資の購入 🔵 | 有効/無効(gold不足) |
| btn-proceed | プライマリボタン | 次ランクへ進む 🔵 | 有効 |

> 🔵 価格序列 `投入枠+1 ≫ 庭拡張 ≒ レシピ解禁`（[`requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) 4章）。投入枠は最大5（+1は一度きり）。

## 状態遷移

### 初期状態
- 🔵 所持ゴールドと各投資の価格を表示。購入可否をゴールド残高で判定。

### 購入不可状態
- 🔵 所持ゴールドが価格未満のカードは購入ボタン無効＋価格を赤系で強調 🟡。

### 購入済み状態
- 🔵 投入枠+1 は最大5到達で「購入済み/上限」表示 🟡。

## アニメーション

| トリガー | アニメーション | 時間 | イージング |
|----------|---------------|------|-----------|
| 画面表示 | フェードイン＋昇格祝福 | 0.4s | ease-out |
| 購入成功 | カード強調＋ゴールド減算 | 0.3s | ease-out |
| 購入不可クリック | 横揺れ（拒否） | 0.15s | linear |

## イベント

| イベント名 | トリガー | 処理内容 |
|-----------|----------|----------|
| OnPurchaseUpgrade | btn-purchase押下 | can_purchase検証→ゴールド消費→恒久効果適用 🔵 |
| OnProceedClicked | btn-proceed押下 | 次ランクのメインゲーム画面へ遷移 🔵 |
