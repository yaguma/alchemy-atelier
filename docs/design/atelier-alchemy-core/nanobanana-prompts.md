# NanoBanana画像生成プロンプト集（アトリエ 画面イメージ）

作成日: 2026-09-10
関連: [`ui-design/overview.md`](ui-design/overview.md)、`docs/dev/plans/`配下の画面帳アーティファクト

各画面のビジュアルイメージをNanoBanana（画像生成AI）で作成するためのプロンプト集。
共通スタイル文を毎回プロンプトの先頭に付けて使用する。

> 🟡 画像生成は日本語の細かい文字を正確に描画するのが苦手なため、UIラベルは短い単語に
> 留めてある。正確な文字が必要な場合は、まず文字なしで背景・UI質感を生成し、後工程で
> テキストを重ねる進め方を推奨する。

---

## 共通スタイル文（毎回プロンプトの先頭に付ける）

```
水彩ファンタジー風のRPGゲーム画面イラスト。16:9の横長構図、Godotエンジンで作られた
インディーゲームのスクリーンショット風。パステルカラーで柔らかい光、にじむような
水彩の質感とペーパーテクスチャ。背景は暖色系のクリーム色を基調とし、ダークな背景・
青紫系の色は使わない。UIパネルは生成り色のパーチメント地に琥珀色(#B4915A前後)の
太めの縁取り、角は丸め、ボタンは緑・クリーム・赤のグラデーションで宝石のような
立体感と縁取りがある。フラットなWebデザインではなく、はめ込み細工のような
ゲームUIの質感で描くこと。実写・3DCGではなく手描き水彩イラスト調。
```

## 1. タイトル画面（SCR-008）

```
[共通スタイル]
シーン: 朝の庭。画面右手前に朝日が昇り、なだらかな緑の丘と庭の茂み・花畑が
画面下部を彩る。左右の端には背の高い草が額縁のように画面を縁取る。
画面左側に寄せて、乳鉢と乳棒の小さな紋章、六芒星の魔法円の飾り模様、
「アトリエ」という大きなロゴ文字、その下に縦に並ぶ4つのメニュー項目
(はじめから / つづきから / せってい / 終了)。一番上の項目だけ金色に光り、
矢印カーソルが添えられている。全体的に温かく、これから始まる冒険を予感させる
柔らかい朝の光。
```

## 2. スロット選択画面（SCR-007）

```

## 3. 庭画面（SCR-001）

```
[共通スタイル、リーフグリーンのアクセント]
シーン: 朝の庭を上から見た仕込みエリア。画面上部に帯状のHUD(ランク表示・

緑の丘がうっすら覗く。

## 4. 調合画面（SCR-002・★ゲームの核心）

```
[共通スタイル、アンバーのアクセント]
シーン: 錬金術の調合台。画面上部にHUDバー。中央に4つの正方形の投入枠
(2つに素材が入り、2つが空の点線枠)。その下に品質・特性・見込み効果を

緑の「調合を実行する」ボタン。背景には暖かい琥珀色の光を放つフラスコの
シルエットと、湯気のような柔らかい光の粒。
```

## 7. 昇格試験画面（SCR-005）

```
[共通スタイル、緊張感のある暖色(琥珀〜朱)のアクセント]
シーン: 試験の間。画面奥に大きな星の紋章が緊迫した暖色の光を放つ。

基調のパレットは崩さない。

## 8. 一時停止メニュー／設定パネル（SCR-009）

```
[共通スタイル]

戻る)、最後のボタンだけ赤系。
