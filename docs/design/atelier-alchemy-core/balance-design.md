## 設計方針

🔵
- **硬い締切**: 各ランクに延長不可の制限ターンを設け、「報酬で稼ぐ余裕があるか、今すぐ貢献度を削るべきか」を毎ランク問う。金でターンを買う手段は意図的に用意しない。
- **真のトレードオフ**: 特性を素材段階で貢献度系/報酬系に二分し、庭の仕込みを先行投資化する（後から取り返しにくい）。
- **段階的開示**: Gランクは特性封印（品質のみ）→ Eで特性解禁 → Dで種類追加、と学習曲線を緩やかにする。
- **一択収束の回避**: 品質 vs 特性、貢献度 vs 報酬のどちらにも収束しないよう、制限ターンと指定調合物で圧をかける。

## 難易度曲線

🔵 コンセプト「体験の強弱カーブ」に準拠（60〜90分／全8ランク）。

```
難易度
  ↑
  │                                    ╭── S（最終試験）
  │                            ╭───────╯
  │                    ╭───────╯ A
  │            ╭───────╯ C-B
  │      ╭─────╯ D
  │   ╭──╯ E（特性解禁）
  │ ╭─╯ F
  │╱ G（チュートリアル）
  └──────────────────────────────────────→ 進行度
     0                                    100%
```

### 序盤（G〜F・0-30%）
- 目標: 🔵 植える→収穫→調合の基本を習得（特性封印）
- 難易度: 低
- 重点: チュートリアル、「混ぜたら作れた」の気持ちよさ

### 中盤（E〜D・30-60%）
- 目標: 🔵 貢献度系/報酬系の二分を理解し、品質 vs 特性の食い合いを最適化
- 難易度: 中
- 重点: 投入枠設計の深化、指定調合物への対応

### 終盤（C〜S・60-100%）
- 目標: 🔵 限られた在庫と枠でトレードオフを詰め、ギリギリの調合設計
- 難易度: 高
- 重点: マスタリー、降格リスク、最終試験

## 経済バランス

🔵 報酬（ゴールド）は「効率を買う投資」に限定。時間（ターン）は買えない。

| リソース | 獲得手段 | 消費手段 | 備考 |
|---------|----------|----------|------|
| ランクHP（敵側） | — | 🔵 調合物の貢献度で減算 | 制限ターン内に0が目標 |
| ゴールド | 🔵 調合物の報酬で獲得 | 🔵 恒久/消耗投資 | 時間延長には使えない |
| 残りターン | 🔵 ランク開始時に付与 | 🔵 ターン終了で消費 | **延長手段なし（硬い締切）** |
| 素材在庫 | 🔵 収穫・触媒購入 | 🔵 調合投入で消費 | 上限の有無は🟡 TBD |

### ショップ価格序列

🔵 `投入枠+1 ≫ 庭拡張 ≒ レシピ解禁 ＞ 触媒 ＞ 種の指名買い`（[`requirements.md`](../../spec/atelier-alchemy-core/requirements.md) 4章）。

| 投資 | 種別 | 相対価格 | 購入タイミング |
|------|------|----------|---------------|
| 投入枠+1 | 恒久 | 最高額 | 工房強化画面のみ |
| 庭拡張 | 恒久 | 高額 | 工房強化画面のみ |
| レシピ解禁 | 恒久 | 高額 | 工房強化画面のみ |
| 触媒（品質+1段素材） | 消耗 | 中額 | ターン中いつでも |
| 種の指名買い | 消耗 | 安価 | ターン中いつでも |

> 🔵 所持ゴールドが価格未満の場合、いずれの購入も不可。具体的な価格額は🟡 TBD。

## 調整ガイドライン

### 調整の優先順位
1. 🔵 制限ターン数（硬い締切の厳しさ＝ゲーム全体の難易度の主軸）
2. 🔵 基礎貢献度／ランクHP（1ランクの攻略時間 10〜20分に収まるか）
3. 🟡 品質倍率・特性ボーナス倍率（品質 vs 特性の食い合いが「一瞬迷う」レベルか）
4. 🟡 ショップ価格（複利ループの立ち上がり速度）
5. 🟡 成熟/枯死ターン（庭の仕込みテンポ）

### 調整時の注意点
- 🔵 品質 vs 特性が「単なる足し算（良い素材で良い品）」に退化していないか（迷いが生まれるか）を最優先で検証（コンセプト6章の最優先仮説）
- 🔵 貢献度 vs 報酬が偽ジレンマ化していないか（硬い締切が効いているか）
- 🟡 指定合致ボーナスが強すぎて「指定を作るだけ」の一択にならないか
- 🔵 数値変更時は `game_balance.gd` を単一の変更点とし、マジックナンバーをコードに散在させない（[`CLAUDE.md`](../../../CLAUDE.md) 定数管理方針）
