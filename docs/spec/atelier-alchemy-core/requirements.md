作成日: 2026-08-03
最終更新日: 2026-08-05（PRレビュー〔7観点〕で指摘されたCritical/Warningのうち、要件レベルの決定が必要な項目をヒアリングの上で反映）
準拠コンセプト: [`../../concept/atelier-concept.md`](../../concept/atelier-concept.md)（v7.0・調合主軸モデル）

> 本書は `atelier-concept.md` の内容を実装可能な要件に落とし込んだものである。数値の多くは仮置き（TBD）であり、バランス調整フェーズで確定する。構造的な決定（勝敗条件・昇格試験の性質、レシピの扱い、触媒の発現ルール等）はコンセプト文書に明記がなかったため、本書作成時および2026-08-04の技術設計レビュー時にヒアリングの上で確定した。

## 概要

- ジャンル: 素材収集×調合×資源管理RPG（ギルドランク制）
- 想定プレイ時間: 1ランク攻略 10〜20分 ／ 全ランク攻略 60〜90分（自由に中断可能。ただしセーブ/ロード機能自体は現バージョンの設計スコープ外）
- プラットフォーム: PC（Godot 4.x + GDScript）

## 1. プレイサイクル

主戦場は「② 調合」。庭（① 仕込み・戦略層）と納品（③ 決算・自動）が調合を挟んで連結する三段構成。

```
① 状況提示
   残りノルマ、本日の指定調合物、素材在庫、庭の育成状況、残りターン数が表示される

② プレイヤーの選択
   - 庭: 何を植えるか（指定調合物から逆算）／収穫するか（Bで抜くかS狙いで賭けるか）
   - 調合: 投入枠（4枠）に在庫の素材をどう組み合わせるか
     （品質を盛るか、枠を割いて特性〔貢献度向き／報酬向き〕を宿すか）

③ 結果反映
   - 調合を実行した場合: 完成品が自動でギルドに納品される
     → ランクノルマが減少（貢献度） and/or ゴールド獲得（報酬）
     → 指定調合物に合致していればボーナス
     → 投入した素材が在庫から消費される
   - ターンを終了すると（調合を実行したかどうかに関わらず、毎ターン必ず）:
     → 庭の生育がターン経過分だけ進む

④ フィードバック
   貢献度反映演出、報酬獲得表示、指定合致ボーナス表示、ランクノルマバーの変化

→ ①に戻る（次のターンへ）
```

このターンループの外側に、以下2層のより大きなループがある。

- **ランクループ**: **制限ターン到達時点で**ランクノルマが0になっていれば昇格試験へ。0でなければ降格（＝ランク文字は下がらず、同一ランクに留まって再挑戦。詳細は「2. 勝敗条件」参照）。ランクノルマが制限ターンより先に0へ到達した場合でも試験への移行は制限ターン到達まで待つ（早期クリア後の残りターンの扱いは「2. 勝敗条件」参照）。
- **ゲーム全体ループ**: G→F→E→D→C→B→A→Sランクを順に攻略し、Sランクの昇格試験クリアでゲームクリア。

## 2. 勝敗条件

- **勝利条件**: 最高ランク（S）の昇格試験をクリアする（ゲームクリア）
- **敗北条件**: 同一ランクで規定回数（TBD、仮に3回）連続して降格した場合、ゲームオーバー
  - ヒアリングにより「降格が続いても無限にやり直せるコージーゲーム」ではなく、**明確な詰み状態を持つ**方針で確定
- **「降格」の定義**: 本書における「降格」は**ランク文字（G→F→E→D→C→B→A→S）が下がることではなく、同一ランクに留まって再挑戦すること**を指す。ゲーム全体ループは常に一方向（昇格のみ）で進行し、ランク文字が実際に下がる遷移は存在しない。「降格回数」は同一ランクでの再挑戦回数のカウンタである
- **降格時のリセット規定**（確定仕様。2026-08-05ヒアリングで新設）: 降格して同一ランクに再挑戦する際、**ランクノルマは当該ランクの上限値に、残りターンは制限ターン数にそれぞれリセットされる**（リセットしなければ、再挑戦した瞬間に制限ターンへ即再到達し降格が連鎖してしまうため）。庭の生育状況・素材在庫・所持ゴールド・恒久投資状況は**リセットされず引き継がれる**。降格回数カウンタ（`demotion_count`）は**昇格に成功した時点で0にリセットされる**（要件冒頭の「同一ランクで規定回数」という定義に対応するカウンタのため）。日替わり指定調合物は降格時点で再抽選する
- **継続不能条件**: なし。デッキ切れのようなシステムはなく、素材が尽きても庭で仕込み直せば回復できる
- **昇格試験**: 通常ターンループと**同じ調合・納品の仕組みを流用した、一発勝負の特殊局面**として実装する（2026-08-04ヒアリングで確定。詳細は「3. プレイヤー操作」内「昇格試験」・「4. ゲーム要素」内「昇格試験（Exam）」参照）
  - **発生タイミング**: 制限ターン**到達時点で**ランクノルマが0になっていれば発生する（ノルマが制限ターンより先に0へ到達しても、試験への移行は制限ターン到達まで待つ。確定仕様）
  - **早期クリア後の残りターン**: ランクノルマが先に0になった場合、制限ターン到達までの残りターンは通常どおりプレイを継続できる（貢献度を稼ぐ意味はなくなるため、報酬〔ゴールド〕を稼ぐボーナス期間として機能する）。これは**意図的な早期クリアボーナス**として設計する（確定仕様。2026-08-05ヒアリングで確定。当初はリスクゼロの抜け道として指摘されたが、早くランクを片付けるほど得をする自然な報酬として明示的に許容する方針とした）
  - 成功 → 次ランクへ昇格し、工房強化画面（恒久投資、購入は任意）へ
  - 失敗 → 降格（同一ランクに留まって再挑戦。降格回数カウントが規定回数に達するとゲームオーバー）
  - 演出の具体的な内容、および試験ノルマの難度係数・試験の制限ターン数の具体値は引き続き🟡TBD（「7. 未確定事項」参照）
- **中断/撤退条件**: セッションはいつでも中断可能。ペナルティなし（ただしセーブ/ロード機能自体が現バージョンでは未実装スコープのため、実際の「再開」体験は別途検討が必要）

## 3. プレイヤー操作

### 庭（仕込み層）
- 種を植える（手持ちの種から選ぶ。マス配置なし、スロット数のみの制限）
- 収穫する（今のタイミングで抜くか、待って品質を上げるか判断。待つほど枯死リスクが上がる）
- 種を指名買いする（狙った特性の弾をピンポイントで購入）

### 調合（主戦場）
- 調合するレシピを選択する（解禁済みレシピから1つを事前に選ぶ。選択したレシピの基礎貢献度・基礎報酬が価値計算に使われる。詳細は「4. ゲーム要素」内「レシピ（Recipe）」参照）
- 投入枠（4枠、強化で+1）に在庫から素材を選んで入れる
- 投入を入れ替える/取り消す
- 調合を実行する（投入枠に最低1個以上の素材が入っている場合のみ実行可能。0個投入では実行不可）

### ギルド納品
- プレイヤー操作なし（自動決算）。結果の確認のみ

### 工房強化・ショップ
- 恒久投資を購入する（投入枠+1／庭拡張／レシピ解禁）※ランク間の工房強化画面でのみ。**購入は任意**であり、何も購入せずに次ランクへ進むことも可能（確定仕様）
- 消耗投資を購入する（触媒／種の指名買い）※ターン中いつでも
- いずれの購入も、所持ゴールドが価格未満の場合は購入不可

### ターン進行
- ターンを終了する（次ターンへ進める）

### 昇格試験
昇格試験は**通常ターンループの調合・納品操作をそのまま流用**する、庭を使わない特殊局面である（2026-08-04ヒアリングで確定）。

- 調合するレシピを選択する（通常ターンと同じ操作）
- 投入枠に**それまでに貯めた在庫**から素材を選んで入れる（**庭での新規の種植え・収穫は一切できない**。事前の仕込みの結果だけで勝負する）
- 調合を実行する（通常ターンと同じ操作。日替わり指定調合物への合致ボーナスは適用されない。**報酬〔ゴールド〕は通常どおり獲得できる**、確定仕様）
- 試験用ノルマ（通常のランクノルマとは別に用意される、後述「4. ゲーム要素」参照）を、超短期（🟡TBD、仮1〜2ターン）の制限ターン以内に0にできれば成功
- 調合を実行せずにターンを進める（在庫や解禁レシピが尽きて調合できない場合の脱出手段として必須。確定仕様。2026-08-05ヒアリングで新設）

## 4. ゲーム要素

### プレイヤー（錬金術師）
- 状態: 所持ゴールド、現在ランク、現ランクでの残りターン数、恒久投資状況（投入枠数・庭スロット数・解禁レシピ一覧）、同ランクでの降格回数
- 変化: ゴールド増減、ランク昇格/降格、投入枠拡張、庭スロット拡張、レシピ解禁

### 素材（Material）
- 状態: 品質スコア（D〜S＝1〜5）、特性タグ（0〜1個。庭で育てた素材は収穫時に1個のみ乱数付与される。触媒等ショップ購入品は購入時に1個固定で付与される。🔵2026-08-05修正、PRレビューWarning対応。旧版は「0〜2個」としていたが、収穫時に付与されるのは常に1個〔下記「変化」参照〕であり2個目に到達する経路が存在しなかったため実態に合わせて修正した）、種別（成熟ターン数が種別ごとに異なる）
- 変化:
  - 庭での生育がターン経過で進行する
  - 収穫時に特性が1つ乱数で付与される（乱数は**分散のみ**で**期待値は動かさない**。種やシナジーで狙いを絞れる。`atelier-concept.md` §5「庭（仕込み層）の仕組み」に準拠）
  - 成熟後、規定ターンを超えて放置すると枯死（全損）する
- 在庫上限: なし（無制限）。庭のスロット数と収穫タイミングの判断のみが供給のボトルネックになる設計とする（確定仕様。2026-08-04のヒアリングにより確定。旧: TBD）

### 特性タグ（Trait）
- 種別:
  - 貢献度系（聖・浄・癒）
  - 報酬系（金・華・稀）
  - 補助系（触媒＝品質+1段 等）※「触媒」はショップで購入できる、補助系特性タグ付きの素材を指す（「ショップ／工房強化」の消耗投資と同一概念）。購入後は在庫に加わり、他の素材と同様に調合投入枠へ入れて使う。ショップ購入品のため品質スコアは種から育てた素材のように可変ではなく、購入時点で固定の基準品質（🟡TBD、仮に3=B相当）を持つ
- 発現条件: 調合の投入枠に**同一特性タグの素材を2個以上**投入すると成果物に発現する（1個のみでは不発）。3個目以降を追加投入してもボーナスは据え置き（2個目以降の重複による追加強化はない）。**ただし補助系特性「触媒」はこの2個以上ルールの対象外**で、触媒タグを持つ素材を1個投入するだけで効果が発揮される（確定仕様。2026-08-04のヒアリングにより確定。旧: TBD）
  - **触媒の効果適用方法**（確定仕様。2026-08-05ヒアリングで再設計）: 触媒の+1段は「投入素材の平均品質を四捨五入した後の、成果物の最終品質」に対して適用する（**素材自身の品質ではなく、成果物の完成後の品質に加算**）。上限5（S）でクランプする。旧仕様（素材自身の品質に+1）は、平均＋四捨五入の後段で効果がほぼ相殺され消えてしまう欠陥があったため撤回した

### レシピ（Recipe）
- 状態: レシピID、名称、基礎貢献度、基礎報酬
- 調合を実行する前に、プレイヤーは解禁済みレシピから1つを選択する（**事前選択方式**、確定仕様。2026-08-04のヒアリングにより確定）。選択したレシピの基礎貢献度・基礎報酬が下記「調合物（Product）」の価値計算に使われる
- 初期状態で解禁されているレシピの一覧、および工房強化「レシピ解禁」で追加されるレシピの具体的な内容は未定（🟡 TBD。「7. 未確定事項」参照）
- **制約**: 初期状態で解禁済みのレシピは**最低1件以上**であることを保証する（確定仕様。2026-08-05ヒアリングで新設。0件だとレシピを選択できず調合が永久に実行不可能になり進行不能になるため）

### 調合物（Product）
- 状態: 品質（投入素材の平均品質）、宿った特性（0〜複数）
- 品質スコアの平均計算で端数が出る場合（例: 品質3と4の素材が混在）は**四捨五入**する（確定仕様。2026-08-04のヒアリングにより確定）
- 価値計算:
  - `貢献度 = 基礎貢献度 × 品質倍率 × 貢献度系特性ボーナス × 指定合致ボーナス`
  - `報酬 = 基礎報酬 × 品質倍率 × 報酬系特性ボーナス × 指定合致ボーナス`
  - 基礎貢献度・基礎報酬は選択した「レシピ（Recipe）」から取得する
  - 発現した特性が複数ある場合、各特性のボーナス倍率は**乗算**で合成する（貢献度系・報酬系それぞれ独立に。確定仕様。2026-08-04のヒアリングにより確定）。例: 聖と浄の両方（ともに貢献度系）が発現した場合、貢献度側は「聖の倍率×浄の倍率」を乗算する。聖（貢献度系）と金（報酬系）のように**系統をまたぐ場合は乗算しない**（貢献度側には聖の倍率のみ、報酬側には金の倍率のみが独立に作用する）

### 調合台（投入枠）
- 状態: 枠数（初期4、恒久投資で+1）
- 制約: 枠数を超えて同時投入できない。また、**最低1個以上の素材が投入されていなければ調合を実行できない**（0個投入では実行不可）

### ギルドランク（審査基準）

🔴2026-08-06修正（世界観整合性の見直し）: 旧版は「ギルドランク（敵）」とし、コンセプト文書がSlay the Spireから転用した「ボス戦」メタファーをそのまま踏襲していたが、錬金術師ギルドの認定制度という世界観には「敵」という表現が合わないため、「審査基準」に改めた。ギルドが各ランクに課す認定基準（ノルマ）を、調合物の納品でこなしていく、という構図は変わらない。
- 状態: ランクノルマ、残りターン数（制限ターン）、現在の日替わり指定調合物
- 変化: 調合物の納品でノルマが減少する（0未満にはならず0でクランプする。超過分は切り捨て）。制限ターン到達時にノルマが0なら昇格試験、0でなければ降格（同一ランクへの再挑戦。「2. 勝敗条件」参照）
- 降格時のリセット: 「2. 勝敗条件」内「降格時のリセット規定」を参照

### 昇格試験（Exam）
- 状態: 試験ノルマ（通常のランクノルマとは別に新規に用意する専用の値）、試験の残りターン数（超短期。🟡具体値TBD、仮1〜2ターン）
- **試験ノルマの算出式**（確定仕様。2026-08-05ヒアリングで再設計）:
  - `試験ノルマ = 当該ランクの1手あたり期待貢献度 × 試験制限ターン数 × 難度係数`
  - `当該ランクの1手あたり期待貢献度 = 当該ランクのランクノルマ上限 ÷ 当該ランクの制限ターン数`
  - `難度係数`は🟡TBD（仮1.0〜1.5、「7. 未確定事項」参照）。旧仕様（`ランクノルマ上限 × 倍率`）は試験制限ターンが1〜2ターンしかないため要求貢献度が通常の20倍超になり成立しなかったため撤回した
- 変化: 調合物の納品で試験ノルマが減少する（ギルドランクノルマと同じ`max(0, ノルマ-貢献度)`のクランプ処理を流用）。試験の制限ターン到達時に試験ノルマが0なら成功（次ランクへ昇格）、0でなければ失敗（降格）
- 通常のギルドランクとの違い:
  - 庭は使用不可（新規の種植え・収穫ができない。それまでに貯めた在庫のみで挑む）
  - 日替わり指定調合物の合致ボーナスは適用されない（確定仕様。2026-08-04ヒアリングで確定）
  - **報酬（ゴールド）は通常どおり獲得できる**（確定仕様。2026-08-05ヒアリングで確定。報酬向き特性を仕込んだプレイヤーが試験で無駄にならないようにするため）
  - 試験専用のノルマを使用する（通常のランクノルマは参照しない）
  - 調合を実行しなくても任意のタイミングでターンを進められる（在庫や解禁レシピが尽きて調合できない場合の脱出手段。確定仕様。2026-08-05ヒアリングで新設）

### 日替わり指定調合物（疑似依頼）
- 状態: 本日ギルドが求めている調合物の条件（品目 or 特性傾向）
- 変化: **毎ターン終了時に**再抽選される（「日替わり」という名称は維持するが、ゲーム内の時間単位は「ターン」に統一する。確定仕様。2026-08-05ヒアリングで明確化。旧: 「日ごとに更新」とだけ書かれておりターンとの対応が未定義だった）。合致した納品に貢献度・報酬ボーナスが付く

### ショップ／工房強化
- 恒久投資（ランクをまたいで残る）: 投入枠+1（最高額）、庭拡張（高額）、レシピ解禁（高額）
- 消耗投資（その場で消費）: 触媒（補助系特性タグ「触媒」を持つ素材）の常備・購入（中額）、種の指名買い（安価）
- 価格序列: `投入枠+1 ≫ 庭拡張 ≒ レシピ解禁 ＞ 触媒 ＞ 種の指名買い`
- 所持ゴールドが価格未満の場合、いずれの購入も不可（「3. プレイヤー操作」参照）
- 金でターン制限を延長する手段は意図的に存在しない（時間は買えない）

## 6. 想定プレイフロー

### Gランク・1ターン目（チュートリアル、特性は封印）
- 状況: ランクノルマ100%、本日の指定調合物「回復薬」、素材は未所持、庭は空
- 行動: 庭に薬草の種を植える → ターンを終了する
- 結果: 庭で薬草の生育が始まる（特性はまだ解禁されていないため品質のみを意識する）

### Gランク・数ターン後
- 状況: 薬草が収穫可能（放置すればS狙いも可能だが、今回はBで確定）
- 行動: 収穫する → 調合台の4枠すべてに薬草（品質B相当）を投入 → 調合を実行する
- 結果: 品質B相当の回復薬が完成 → 自動でギルドに納品 → 指定調合物に合致しボーナス込みでランクノルマが減少

### Eランク以降（特性解禁後）
- 状況: 本日の指定調合物は「貢献度重視の品」。在庫には品質A・無特性の素材が2個、特性(聖)付きの品質B素材が2個ある
- 行動: 投入枠4枠すべてを埋める。特性(聖)持ちの品質B素材2個（発現条件を満たす最低数）＋品質A・無特性の素材2個（残り2枠を最高品質で補い、品質低下を抑える判断）を投入する
- 結果: 貢献度系特性(聖)が発現し、品質はA4個で埋めた場合（品質A相当）よりやや落ちる（A×2・B×2の平均）が、貢献度ボーナスの乗った調合物が完成 → 大きくランクノルマを削る

### ランクの制限ターン到達時
- 状況: 残りターンが0になり、ランクノルマが0まで削り切れている
- 行動: 昇格試験（一発勝負の特殊局面）に自動で移行する。庭は使えず、それまでに貯めた在庫のみで、通常と同じレシピ選択→投入枠→調合実行を、超短期の試験制限ターン内で繰り返す
- 結果:
  - 試験ノルマを0にできた → 成功 → 次ランクへ昇格、工房強化画面で恒久投資を選択できる（購入は任意）
  - 試験制限ターン到達時に試験ノルマが残っている → 失敗 → 降格。同ランクでの降格回数が加算される。規定回数（仮3回）に達していればゲームオーバー、達していなければ同ランクに再挑戦
