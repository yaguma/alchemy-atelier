## ペルソナ

### ペルソナ1: 錬金術師見習い（プレイヤー）

- **役割**: ギルドランク制デッキ構築RPG「Atelier」のプレイヤー。庭で素材を仕込み、調合で品目を作り、ギルドへ納品してランクを上げていく
- **目的**: 手持ちの種を効率よく育て、調合に必要な品質・特性を持つ素材を安定して確保したい。品質を盛るか特性を宿すかのトレードオフを庭の時点から先読みして計画したい
- **技術レベル**: ゲームプレイヤーとしては初級〜中級（ゲームUI操作に習熟している必要はない）。庭画面単体で完結した操作フローが理解できることを前提とする

## エピック1: 種植え・生育管理

### US-001: 手持ちの種を庭に植える 🔵

**私は** 錬金術師見習い **として**
**手持ちの種一覧から種を選び、庭の空きスロットに植え付けたい**
**そうすることで** 将来のターンで素材を収穫できる状態を作れる

- **関連要件**: FR-001, FR-005, FR-006, FR-101, FR-102, FR-109, FR-110
- **優先度**: Must Have
- **受入基準**: AC-001, AC-002, AC-003

### US-002: 庭スロットの状態を一目で把握する 🔵

**私は** 錬金術師見習い **として**
**各庭スロットが「空き」「生育中」「収穫可能」「枯死警告」のどれかを視覚的に判別したい**
**そうすることで** 次に何をすべきか（植える/待つ/収穫する）を迷わず判断できる

- **関連要件**: FR-002, FR-201, FR-202, FR-203, FR-204
- **優先度**: Must Have
- **受入基準**: AC-010

### US-003: ターンを終了して生育を進める 🔵

**私は** 錬金術師見習い **として**
**庭画面でターンを終了する操作をしたい**
**そうすることで** 植えた種が1ターン分生育し、次の判断（収穫するか待つか）の材料が得られる

- **関連要件**: FR-103
- **優先度**: Must Have
- **受入基準**: AC-004

## エピック2: 収穫と品質・特性

### US-004: 成熟した素材を収穫する 🔵

**私は** 錬金術師見習い **として**
**収穫可能になったスロットから素材を収穫したい**
**そうすることで** 調合に使える`MaterialInstance`（品質・特性付き）を在庫に加えられる

- **関連要件**: FR-003, FR-004, FR-104, FR-105, FR-106, FR-108
- **優先度**: Must Have
- **受入基準**: AC-005, AC-007

### US-005: 収穫を待ってより高い品質を狙う 🟡

**私は** 錬金術師見習い **として**
**成熟したスロットをすぐ収穫せず、あえて待って品質上昇を狙いたい**
**そうすることで** リスク（枯死）と引き換えに、より高品質な素材を得られる可能性を高められる

- **関連要件**: FR-107, FR-302
- **優先度**: Should Have
- **受入基準**: AC-006

---

## エピック3: 枯死管理・資産維持

### US-006: 枯死を見逃さず自動的に処理してもらう 🔵

**私は** 錬金術師見習い **として**
**収穫し忘れて枯死猶予ターンを超えたスロットが自動的に検出・解放されてほしい**
**そうすることで** 手動での枯死チェック漏れによる庭の詰まりを防げる

- **関連要件**: FR-111, FR-204, FR-303
- **優先度**: Must Have
- **受入基準**: AC-008, AC-010

### US-008: 降格してもこれまで育てた庭の資産を失わない 🔵

**私は** 錬金術師見習い **として**
**ランクが降格しても庭の生育状況・素材在庫・種在庫が維持されてほしい**
**そうすることで** 降格のペナルティが「庭を1からやり直し」という理不尽な喪失にならず、納得感を持って再挑戦できる

- **関連要件**: FR-205
- **優先度**: Should Have
- **受入基準**: AC-009

## エピック4: 将来機能への導線（プレースホルダー）

### US-007: ショップへの導線から種の指名買いへ進みたい（将来機能） 🟡

**私は** 錬金術師見習い **として**
**庭画面からショップ画面へのボタンを押して遷移したい**
**そうすることで** （将来的に）欲しい種を指名して購入できる導線を庭の中から把握できる

- **関連要件**: FR-301, FR-405
- **優先度**: Could Have
- **受入基準**: AC-012

```
   US-002                    US-003                              US-006
```
