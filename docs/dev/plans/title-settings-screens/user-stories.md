## ペルソナ

### ペルソナ1: 新規/復帰プレイヤー

- **役割**: ゲームを起動したばかりのプレイヤー（初回起動・久しぶりの起動の両方を含む）
- **目的**: 迷わず「はじめる」を選んでゲームに入りたい。設定を変えたければ迷わず「せってい」に到達したい
- **技術レベル**: 初級（PCゲームのメニュー操作に慣れていない場合を含む）

### ペルソナ2: プレイ中に環境を調整したいプレイヤー

- **役割**: 庭/調合/工房いずれかのフェーズをプレイ中のプレイヤー
- **目的**: プレイを中断（フェーズ遷移やセーブへの影響）せずに音量やウィンドウ表示を調整したい
- **技術レベル**: 中級（既にゲームの基本操作を理解している）

## エピック1: タイトル画面からのゲーム開始

### US-001: はじめるボタンでスロット選択へ進む 🔵

**私は** 新規/復帰プレイヤー **として**
**タイトル画面で「はじめる」を押してスロット選択画面に進みたい**
**そうすることで** 新規開始／つづきからのプレイをすぐに選べる

- **関連要件**: FR-001, FR-101, FR-405
- **優先度**: Must Have
- **受入基準**: AC-001, AC-003

### US-002: シンプルな2択メニューだけを見る 🔵

**私は** 新規/復帰プレイヤー **として**
**タイトル画面で「はじめる」「せってい」の2つのボタンだけを見たい**
**そうすることで** 何を選べばよいか迷わずに済む

- **関連要件**: FR-002, FR-406
- **優先度**: Must Have
- **受入基準**: AC-002, AC-014

## エピック2: タイトル画面からの設定変更

### US-101: せっていボタンで設定パネルを開く 🔵

**私は** 新規/復帰プレイヤー **として**
**タイトル画面で「せってい」を押して設定パネルを開きたい**
**そうすることで** ゲームを始める前に音量や画面表示を自分好みに調整できる

- **関連要件**: FR-006, FR-102
- **優先度**: Must Have
- **受入基準**: AC-004

### US-102: BGM/SE音量を即時反映で調整する 🔵

**私は** プレイヤー **として**
**設定パネルでBGM音量・SE音量のスライダーを動かしたい**
**そうすることで** 操作した結果（音量の変化）をその場で確認しながら好みの音量に調整できる

- **関連要件**: FR-004, FR-104, FR-105
- **優先度**: Must Have
- **受入基準**: AC-006

### US-103: 画面モードを切り替える 🔵

**私は** プレイヤー **として**
**設定パネルでウィンドウモード（フルスクリーン/ウィンドウ）を切り替えたい**
**そうすることで** 自分のプレイ環境に合った表示形式でプレイできる

- **関連要件**: FR-004, FR-106
- **優先度**: Must Have
- **受入基準**: AC-007

### US-104: 演出簡略化フラグを設定する（将来の演出実装向けの土台） 🟡

**私は** プレイヤー **として**
**設定パネルで「演出簡略化」のトグルを操作したい**
**そうすることで** （将来演出が実装された際に）テンポよくプレイできる状態を今のうちに選んでおける

- **関連要件**: FR-004, FR-302
- **優先度**: Should Have
- **受入基準**: AC-008

### US-105: 設定パネルを閉じて自動保存される 🔵

**私は** プレイヤー **として**
**設定パネルを閉じるだけで設定が保存されてほしい**
**そうすることで** 明示的な保存操作を意識せずに次回起動時も同じ設定でプレイできる

- **関連要件**: FR-107, FR-108, FR-303
- **優先度**: Must Have
- **受入基準**: AC-009, AC-013

## エピック3: ゲームプレイ中の設定アクセス

### US-201: 歯車ボタンでいつでも設定を開ける 🔵

**私は** プレイ中に環境を調整したいプレイヤー **として**
**どのフェーズ画面からでもRankHudの歯車アイコンを押して設定パネルを開きたい**
**そうすることで** プレイを中断してタイトルに戻ることなく環境調整できる

- **関連要件**: FR-006, FR-007, FR-103, FR-407
- **優先度**: Must Have
- **受入基準**: AC-005, AC-013

### US-202: 設定操作がゲーム進行に影響しないことを確認する 🔵

**私は** プレイ中に環境を調整したいプレイヤー **として**
**設定パネルを開閉してもゲームのフェーズやセーブ状態が一切変わらないことを期待したい**
**そうすることで** 安心して調合中やギルド納品中に設定を開ける

- **関連要件**: FR-201, FR-202, FR-402, FR-403
- **優先度**: Must Have
- **受入基準**: AC-011

---

## エピック4: 設定データの堅牢性

### US-301: 破損した設定ファイルでもデフォルト値で起動できる 🔵

**私は** プレイヤー **として**
**`settings.json`が存在しない・壊れている場合でもゲームが正常に起動してほしい**
**そうすることで** ファイル破損によってゲームが起動できなくなる事態を避けられる

- **関連要件**: FR-005, FR-008, FR-404
- **優先度**: Must Have
- **受入基準**: AC-010
