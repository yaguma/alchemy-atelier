## AC-001: [FR-001] BootSceneがTitleScreenへ遷移する 🔵

**関連**: FR-001, US-001

### Given（前提条件）
- ゲームが起動され、`BootScene`のマスターデータ検証が成功している

### When（実行条件）
- `BootScene._ready()`の遷移処理が実行される

### Then（期待結果）
- 遷移先パスが`res://features/title/ui/title_screen.tscn`であること
- 従来の`res://features/save_load/ui/slot_select_screen.tscn`への直接遷移が行われないこと

### テストチェックリスト

- [ ] **正常系**: `BootScene.get_requested_next_scene_path()`が`title_screen.tscn`のパスを返す 🔵
- [ ] **異常系**: マスターデータ検証失敗時は遷移が要求されない（`_requested_next_scene_path`が空文字列のまま） 🔵
- [ ] **境界値**: `scene_transition_enabled = false`（テスト用）でも遷移先パスの決定自体は行われる 🟡

## AC-011: [FR-201, FR-202, FR-402, FR-403] 設定パネルはGameState/SaveServiceに影響しない 🔵

- [ ] **異常系**: 設定パネル内のボタン誤操作（存在しないシグナル接続等）が`GameState`のsignalを誤発火させない 🟡

## 横断的受入基準

### パフォーマンス（NFR-001, NFR-002）

- [ ] 音量・ウィンドウモード変更操作から反映までの体感遅延がないこと（数フレーム以内） 🟡
- [ ] `TitleScreen`・`SettingsPanel`のスクリプトに`_process()`定義が存在しないこと（イベント駆動のみで実装されていること） 🟡

### セキュリティ（NFR-101, NFR-102）

- [ ] 破損・型不正な`settings.json`を読み込んでもクラッシュせずデフォルト値にフォールバックすること（AC-010と同一観点） 🔵
- [ ] 設定ファイルの内容が`Expression.execute()`等の動的コード評価に渡されていないことをコードレビューで確認する 🔵

### アクセシビリティ／ユーザビリティ（NFR-201, NFR-202, NFR-203）

- [ ] `TitleScreen`・`SettingsPanel`の全テキストが日本語で、`main_theme.tres`のフォントが適用されていること 🔵
- [ ] 新規UI要素の色・角丸・余白が`UiTheme`定数経由で指定され、ハードコードされた`Color(...)`リテラルが存在しないこと 🔵
- [ ] 歯車ボタンが通常フェーズ・昇格試験中の両方で押下可能であること 🟡
