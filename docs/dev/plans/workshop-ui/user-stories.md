## ペルソナ

### ペルソナ1: 錬金術師プレイヤー

- **役割**: 「Atelier」のシングルプレイヤー。庭での仕込み・調合・ギルド納品を繰り返しながらランクを上げ、ときどき工房強化・ショップ画面でゴールドを投資に回す
- **目的**: ターン中は消耗投資（触媒・種の指名買い）で目先の調合を有利にし、ランク間では恒久投資（投入枠+1・庭拡張・レシピ解禁）で長期的な強さを積み上げる
- **技術レベル**: ゲーム内操作のみ（開発者ではない）。ボタンのラベルと状態表示だけで「今これは買えるか」を即座に判断したい

## エピック1: 工房強化・ショップ画面の表示

### US-001: アイテム一覧を確認する 🔵

**私は** 錬金術師プレイヤー **として**
**恒久投資・消耗投資それぞれのアイテムを名称・価格付きで一覧表示したい**
**そうすることで** 何にいくら投資できるかを一目で把握できる

- **関連要件**: FR-001, FR-003, FR-004, FR-005, FR-007
- **優先度**: Must Have
- **受入基準**: AC-001, AC-002, AC-003

### US-002: 所持ゴールドを確認する 🔵

**私は** 錬金術師プレイヤー **として**
**画面上で現在の所持ゴールドを確認したい**
**そうすることで** どのアイテムが買えるかを画面内だけで判断できる

- **関連要件**: FR-002
- **優先度**: Must Have
- **受入基準**: AC-001

### US-003: タブを切り替えて恒久/消耗投資を見る 🔵

**私は** 錬金術師プレイヤー **として**
**恒久投資タブと消耗投資タブを切り替えて見たい（恒久投資タブはランク間の工房強化画面遷移時のみ選べるようにしたい）**
**そうすることで** 通常ターン中に誤って恒久投資枠にアクセスすることなく、消耗投資だけを安全に利用できる

- **関連要件**: FR-003, FR-105, FR-201, FR-202, FR-203
- **優先度**: Must Have
- **受入基準**: AC-004, AC-005

## エピック2: 購入操作

### US-101: アイテムを購入する 🔵

**私は** 錬金術師プレイヤー **として**
**購入可能なアイテムの購入ボタンを押して即座に購入したい**
**そうすることで** ゴールドを消費して工房強化・消耗品を手に入れ、以降のプレイに反映できる

- **関連要件**: FR-101, FR-102, FR-206, FR-403
- **優先度**: Must Have
- **受入基準**: AC-008, AC-013

### US-102: 購入失敗時にフィードバックを受け取る 🔵

**私は** 錬金術師プレイヤー **として**
**購入に失敗した場合（想定外にゴールド不足や権限エラーが起きた場合）、その旨のメッセージを見たい**
**そうすることで** 何も起きなかったのか失敗したのかを迷わず判断できる

- **関連要件**: FR-101, FR-103
- **優先度**: Must Have
- **受入基準**: AC-009

### US-103: 購入できないアイテムの理由を知る（ゴールド不足/購入済み） 🔵

**私は** 錬金術師プレイヤー **として**
**購入できないアイテムについて、「ゴールドが足りないのか」「もう買い切ったのか」を区別して見たい**
**そうすることで** ゴールドを貯めるべきか、諦めて別のアイテムを検討すべきかをすぐ判断できる

- **関連要件**: FR-008, FR-204, FR-205, FR-404
- **優先度**: Must Have
- **受入基準**: AC-006, AC-007, AC-013

## エピック3: 画面を閉じる

### US-201: 画面を閉じて元の画面/次のフェーズへ進む 🔵

**私は** 錬金術師プレイヤー **として**
**購入してもしなくても、いつでも「閉じる」ボタンで画面を抜けたい（恒久投資の強制表示中でも購入せず進めたい）**
**そうすることで** 投資判断に迷ったまま画面に足止めされることなくプレイを続けられる

- **関連要件**: FR-006, FR-104
- **優先度**: Must Have
- **受入基準**: AC-010

```

   US-201         US-003                          US-003              US-001         US-101/US-102        US-201
```

```
庭/調合画面でショップボタンを押す想定 → 工房強化画面が開く（恒久投資タブは非活性） → 消耗投資タブでアイテムを確認 → 購入する/購入できない理由を確認 → 閉じるボタンで元の画面へ戻る想定
   （画面遷移自体は本Plan外）              US-003                                        US-001/US-103              US-101/US-102/US-103         US-201（screen_closed発行のみ）
```
