## ペルソナ

### ペルソナ1: アトリエプレイヤー

- **役割**: 「Atelier」をプレイする錬金術師視点のユーザー。庭で素材を仕込み、調合画面で品質と特性のトレードオフに悩みながら調合物を作る
- **目的**: 手持ちの素材とレシピから、指定調合物ノルマに合致する高品質な調合物を作り、ギルドへ納品して報酬を得る
- **技術レベル**: ゲームUI操作に慣れた一般プレイヤー（マウス操作のみを前提とし、キーボード・スクリーンリーダー操作は想定しない）

---

## エピック1: レシピ選択と投入枠管理

### US-001: 在庫から投入枠へ素材を配置する 🔵

**私は** アトリエプレイヤー **として**
**在庫一覧の素材カードをクリックして投入枠へ配置したい**
**そうすることで** ドラッグ操作なしに素早く調合の準備を進められる

- **関連要件**: FR-001, FR-003, FR-004, FR-005, FR-101
- **優先度**: Must Have
- **受入基準**: AC-002, AC-003, AC-004

### US-002: 投入枠から在庫へ素材を戻す 🔵

**私は** アトリエプレイヤー **として**
**投入済みの枠をクリック（またはクリア操作）して素材を在庫へ戻したい**
**そうすることで** 投入内容を気軽に組み直せる

- **関連要件**: FR-102
- **優先度**: Must Have
- **受入基準**: AC-005

### US-003: レシピを選択する 🟡

**私は** アトリエプレイヤー **として**
**レシピ一覧から作りたいレシピをクリックで選択したい**
**そうすることで** 目的の調合物に向けて投入計画を立てられる

- **関連要件**: FR-002, FR-103
- **優先度**: Must Have
- **受入基準**: AC-001, AC-006

### US-004: 投入枠が埋まっている状態でも安全に操作する 🟡

**私は** アトリエプレイヤー **として**
**投入枠が全て埋まっている間は追加クリックが誤動作しないでほしい**
**そうすることで** 意図しない状態変化に悩まされず落ち着いて調合内容を確認できる

- **関連要件**: FR-203
- **優先度**: Should Have
- **受入基準**: AC-010

## エピック2: ライブプレビュー

### US-101: 調合結果の見込みをリアルタイムで確認する 🔵

**私は** アトリエプレイヤー **として**
**投入枠の内容を変えるたびに品質・貢献度・報酬の見込みを即座に確認したい**
**そうすることで** 「品質を盛るか特性を宿すか」のトレードオフを実行前に検討できる（ゲームコンセプトの核心体験）

- **関連要件**: FR-006, FR-104
- **優先度**: Must Have
- **受入基準**: AC-007

### US-102: 発現した特性を視覚的に把握する 🟡

**私は** アトリエプレイヤー **として**
**発現済みの特性をアイコンやタグで見分けたい**
**そうすることで** どの投入が特性発現に寄与したかを直感的に理解できる

- **関連要件**: FR-301
- **優先度**: Could Have
- **受入基準**: AC-007

## エピック3: 調合実行とフィードバック

### US-201: 調合を実行して成果物を得る 🔵

**私は** アトリエプレイヤー **として**
**「調合実行」ボタンを押して調合を確定したい**
**そうすることで** 準備した投入内容から実際の成果物を得られる

- **関連要件**: FR-105, FR-106
- **優先度**: Must Have
- **受入基準**: AC-008

### US-202: 調合に失敗した理由を知る 🔵

**私は** アトリエプレイヤー **として**
**調合実行が失敗した場合にその理由を画面上で確認したい**
**そうすることで** 何を直せば良いか理解して次の操作に進める

- **関連要件**: FR-107
- **優先度**: Must Have
- **受入基準**: AC-009

### US-203: 投入内容が不十分な間は誤操作を防止したい 🔵

**私は** アトリエプレイヤー **として**
**レシピ未選択や投入0個の状態では「調合実行」ボタンが押せないでほしい**
**そうすることで** 無効な操作によるエラー表示に煩わされない

- **関連要件**: FR-201, FR-202
- **優先度**: Must Have
- **受入基準**: AC-010

## エピック4: プレースホルダー導線（ターン終了・ショップ）

### US-301: ターンを終えて調合物を納品する 🔵

**私は** アトリエプレイヤー **として**
**「ターンを終了する」ボタンを押して未納品の調合物をギルドへ納品したい**
**そうすることで** 作った調合物を成果として確定できる（庭の生育進行等の統一ターン処理は別Planで実装される前提のプレースホルダーとして）

- **関連要件**: FR-108, FR-109
- **優先度**: Must Have
- **受入基準**: AC-011

### US-302: ショップへの導線を確認する 🔵

**私は** アトリエプレイヤー **として**
**「ショップ」ボタンを押した際に何らかの反応（画面遷移は未実装でも導線自体）があってほしい**
**そうすることで** 将来ショップ画面が実装された際にスムーズに繋がることを開発側が確認できる

- **関連要件**: FR-110
- **優先度**: Should Have
- **受入基準**: AC-012

### US-303: 投入操作に軽い視覚フィードバックが欲しい 🟡

**私は** アトリエプレイヤー **として**
**素材を投入枠へ配置した際に軽いアニメーションが欲しい**
**そうすることで** 操作の手応えを感じながら調合を組み立てられる

- **関連要件**: FR-302
- **優先度**: Could Have
- **受入基準**: -（本Planでは任意要件のためAC未定義）

**私は** アトリエプレイヤー **として**
**あと1個素材を足せば発現する特性のヒントを見たい**
**そうすることで** 特性発現に必要な投入を逆算しやすくなる

- **関連要件**: FR-404
- **優先度**: Won't Have
- **受入基準**: AC-013
- **除外理由**: ヒアリング スコープ確定事項7で別task（TBD）として明示的に除外

- **優先度**: Won't Have

### US-404: 画面上部のタブから他フェーズへ切り替えたい 🔴

**私は** アトリエプレイヤー **として**
**調合画面から庭・ギルド納品・ショップへタブ切り替えしたい**
**そうすることで** フェーズ間をシームレスに行き来できる

- **関連要件**: FR-405

- **受入基準**: AC-013
- **除外理由**: ヒアリング スコープ確定事項1・8でMainScene統合・RankHudは本Plan外と確認済み（gardenプランでも未実施）

## ユーザージャーニー

### ジャーニー1: レシピ選択から調合成功まで

```
レシピを選ぶ → 素材を投入枠へ配置 → プレビューで見込みを確認 → 調合実行 → 完了トースト・投入枠リセット
   US-003         US-001              US-101                US-201        US-201
```

### ジャーニー2: 投入内容の見直しから調合失敗の回復まで

```
投入内容を組み直す → 実行不可のまま操作 → ボタン無効化に気づく → 投入を追加 → 実行 → 失敗トースト → 原因を直して再実行
    US-001/US-002        US-203              US-203              US-001    US-201    US-202          US-001〜US-201
```

### ジャーニー3: ターン終了とプレースホルダー導線の確認

```
調合を繰り返す → ターンを終了する → 納品完了トースト → （将来）ショップ導線を確認
   US-201             US-301               US-301              US-302
```
