## AC-001: [FR-002] レシピ一覧表示 🔵

**関連**: FR-002, US-003

### Given（前提条件）
- `AlchemyScreen`がシーンツリーに追加され`_ready()`が完了している
- `GameState.get_state().unlocked_recipe_ids`に0件以上のレシピIDが存在する

### When（実行条件）
- `AlchemyScreen`が初回表示される、または`GameState.get_state()`を再取得する`_refresh()`が呼ばれる

### Then（期待結果）
- `unlocked_recipe_ids`に含まれる全レシピが一覧として表示される
- 未解放レシピ（`unlocked_recipe_ids`に含まれない）は表示されない

### テストチェックリスト

- [ ] **正常系**: レシピが2件以上解放済みの状態で全件が一覧に表示される 🔵
- [ ] **異常系**: `unlocked_recipe_ids`が空配列の場合、一覧が空表示となりクラッシュしない 🟡
- [ ] **境界値**: レシピが1件のみ解放済みの場合に正しく1件だけ表示される 🟡

## AC-002: [FR-003] 在庫一覧表示 🔵

**関連**: FR-003, US-001

### Given（前提条件）

### Then（期待結果）
- 在庫内の全`MaterialInstance`がカードとして一覧表示される
- 既に投入枠へ配置済みの素材は在庫一覧から除外される

### テストチェックリスト

- [ ] **正常系**: 在庫に複数の素材がある場合、全件がカード表示される 🔵
- [ ] **異常系**: 在庫が0件の場合、一覧が空表示となりクラッシュしない 🟡
- [ ] **境界値**: 大量の素材（庭の複数スロット分収穫済み）が在庫にある場合も表示が破綻しない 🟡

## AC-004: [FR-101] 在庫カードクリックで投入枠へ配置 🔵

**関連**: FR-101, US-001

- 在庫に未投入の素材が1件以上存在する

- [ ] **正常系**: 空き枠がある状態で在庫カードをクリックすると投入枠へ配置される 🔵

- [ ] **境界値**: 投入枠が残り1つの状態でクリックした場合、その1枠に正しく配置される 🟡

## AC-007: [FR-006, FR-104, FR-301] ライブプレビューの計算と再計算タイミング 🔵

**関連**: FR-006, FR-104, FR-301, US-101, US-102

### Given（前提条件）
- レシピが選択され、投入枠に1件以上の素材が投入されている
- `GameState.get_state().current_daily_order`が設定されている場合を含む

### When（実行条件）
- 投入枠の内容が変化する（配置・返却）、またはレシピ選択が変化する

### Then（期待結果）
- `QualityCalculator.calculate_quality` → `TraitActivation.resolve_traits` → `ProductValueCalculator.calculate_contribution` / `calculate_reward` → `DeliveryResolver.resolve`（`features/guild/logic/delivery_resolver.gd`）までを同期呼び出しし、指定合致ボーナス反映後の最終見込み貢献度・報酬が表示される
- 変更のたびに（都度）再計算が実行され、古い計算結果が残らない

### テストチェックリスト

- [ ] **正常系**: 投入枠へ素材を1件追加するたびにプレビュー値が更新される 🔵
- [ ] **異常系**: レシピ未選択の状態ではプレビューが計算されず空/初期表示のままである 🔵
- [ ] **境界値**: 投入枠が1件も無い状態（0個投入）ではプレビューが計算されない、または実行不可を示す表示になる 🟡

### テストチェックリスト

## AC-009: [FR-107] 調合実行の失敗パス（エラーコード別） 🔵

**関連**: FR-107, US-202

### Given（前提条件）
- 何らかの理由で`GameState.execute_alchemy()`が失敗する状況が発生している

### When（実行条件）
- `GameState`が`execute_alchemy_failed(recipe_id, error_code)`シグナルを発行する

### Then（期待結果）
- `error_code`に応じたメッセージのトーストが表示される
- 投入枠・在庫の状態は変更されない（副作用なし）

### テストチェックリスト

- [ ] **異常系**: `error_code == "unknown_recipe_id"`（存在しないレシピID）でトーストが表示される 🔵

- [ ] **異常系**: `error_code == "material_not_owned"`（在庫に存在しない素材ID）でトーストが表示される 🔵
- [ ] **異常系**: `error_code == "duplicate_material_in_slot"`（同一素材IDの重複投入）でトーストが表示される 🔵
- [ ] **異常系**: `error_code == "slot_execution_invalid"`（`SlotState.can_execute()`が実行直前の再評価でfalse）でトーストが表示される 🔵

## AC-010: [FR-201, FR-202, FR-203] ボタン活性制御と境界値 🔵

**関連**: FR-201, FR-202, FR-203, US-203, US-004

### Given（前提条件）
- `AlchemyScreen`が表示されている

### When（実行条件）
- レシピ選択状態・投入枠の素材数が変化する

### Then（期待結果）
- レシピ未選択の間、「調合実行」ボタンは無効化される
- 投入0個、または投入枠上限を超える状態に相当する間、「調合実行」ボタンは無効化される
- 投入枠が全て埋まっている間、追加の在庫クリックは新規配置に反映されない

### テストチェックリスト

- [ ] **正常系**: レシピ選択済み・投入1件以上・上限以内の場合にボタンが活性化する 🔵
- [ ] **境界値**: 投入0個（レシピ選択済みだが未投入）の場合にボタンが無効化される 🔵
- [ ] **境界値**: 投入枠の上限数と同数投入した場合はボタンが活性化し、上限を超える投入操作は発生しない（UIが上限枠数以上を受け付けない設計になっている） 🔵

## AC-014: [FR-001, NFR-101, CON-007] signal購読・解除とテスト安全性 🔵

**関連**: FR-001, NFR-101, US-001

### Given（前提条件）
- `AlchemyScreen`が`GameState`のsignal（`product_crafted`, `execute_alchemy_failed`, `delivered`等）を購読している

### When（実行条件）
- `AlchemyScreen`が`_exit_tree()`によりシーンツリーから除去される
- または、GdUnit4統合テストで`monitor_signals(GameState, ...)`を用いて検証する

### Then（期待結果）
- `_exit_tree()`内で全ての`GameState`シグナル購読が`is_connected()`確認の上`disconnect()`される
- テストコードは`monitor_signals(GameState, false)`を明示し、Autoloadである`GameState`がテスト終了時に誤って解放されない

### テストチェックリスト

- [ ] **正常系**: `AlchemyScreen`破棄後に`GameState`のシグナルを発行しても例外・警告が発生しない（購読が正しく解除されている） 🔵
- [ ] **異常系**: `monitor_signals(GameState)`を第2引数省略で呼び出した場合に発生する`previously freed`エラーが、本Planのテストコードでは発生しない（`monitor_signals(GameState, false)`を徹底） 🔵
