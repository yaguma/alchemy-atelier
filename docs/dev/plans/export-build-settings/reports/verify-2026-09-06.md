## タスク004の詳細

### 環境構築（本Planのタスク外だが検証のため実施）

- ローカルにGodot 4.7.1のエクスポートテンプレートが未導入だったため、ユーザーの許可を得てGodot公式GitHubリリース（`Godot_v4.7.1-stable_export_templates.tpz`, 約1.2GB）からダウンロードした
- 🔴 **重要な副次発見**: 作業中、C:ドライブの空き容量が約110MBまで逼迫していることが判明（本Planとは無関係の既存問題）。フルテンプレート（Android/iOS/macOS/Web含む、展開後数GB規模）の展開は「ディスクに十分な空き領域がありません」で失敗した
  - 対応: `.NET System.IO.Compression.ZipFileExtensions`で該当エントリのみを個別展開する方式に切り替え、本プロジェクトに必要な`windows_debug_x86_64.exe` / `windows_debug_x86_64_console.exe` / `windows_release_x86_64.exe` / `windows_release_x86_64_console.exe`（合計約203MB）のみを`%APPDATA%/Godot/export_templates/4.7.1.stable/`に配置した
  - ダウンロード元の`.tpz`（1.2GB）は展開後に削除済み
  - **ユーザーへの申し送り事項**: C:ドライブの空き容量が恒常的に少ない状態なのだ。本Plan外の問題だが、他の作業（特に大きめのビルド・依存関係インストール）に影響しうるため、別途空き容量の確保を推奨する

### 実行結果

```
godot --headless --path atelier --export-debug "Windows Desktop" build/windows/atelier-alchemy.exe
```

- 初回実行: `atelier/build/windows/`ディレクトリが存在せず「指定されたエクスポートパスが存在しません」で失敗（出力先ディレクトリの事前作成が必要と判明。README/タスクへの追記は不要と判断したが、初回セットアップ時の既知の注意点として記録する）
- ディレクトリ作成後、再実行して成功。生成物:
  - `atelier/build/windows/atelier-alchemy.exe`（約109MB、`embed_pck=true`によりPCK込みの単一exe）
  - `atelier/build/windows/atelier-alchemy.console.exe`（コンソールラッパー、約50KB）
- `atelier-alchemy.console.exe --headless`を15秒間実行し、起動シーケンス（`boot.tscn`のマスターデータ検証等）に起因するエラーが出力されないことを確認した。出力された`ERROR: BUG: Unreferenced static string...`等は`timeout`コマンドによる強制終了（SIGTERM）時のGodotエンジン内部の後片付けログであり、アプリケーション側の起動失敗を示すものではない
- `git status --ignored`で`atelier/build/`がGit管理対象外であることを再確認した
