# 手動プレイテスト手順書（結合プレイ確認）

> Plan: `debug-playtest-support` タスク004。CLAUDE.md「次のステップ」記載の
> 「5機能を通した結合プレイ（庭→調合→ギルド納品→ランク進行→工房強化のループが実機で通しで回るか）
> の確認はまだ行われていない」に対応する、人間プレイ用のチェックリスト。
>
> G→F→Eの2段階昇格ループ自体は`test_main_scene_full_loop_playthrough.gd`（GdUnit4シーンテスト）で
> 既に自動検証済みのため、本手順書は**自動テストでは見えない観点**（画面遷移の見た目・
> パフォーマンス・日本語表示崩れ・操作感）に絞る。DebugPanel（画面左上の半透明パネル、
> デバッグビルドのみ表示）を使ってG〜S全ランクを素早く辿れるようにしてある。

## 事前準備

1. Godotエディタで`atelier/`プロジェクトを開き、`scenes/main.tscn`または`scenes/boot.tscn`を再生する（F5/F6）。
   - `godot --path atelier`（`run_in_background`推奨）でも可。
2. 画面左上に半透明の黒いパネルが3ボタン（`G+1000` / `ノルマ即達成` / `次ランクへ`）とともに表示されていることを確認する。
   - 表示されない場合、デバッグビルドとして起動できていない可能性がある（`OS.is_debug_build()`が偽）。エクスポート済みRelease版ではこのパネルは自動的に消えるのが正しい挙動であることに注意（今回のプレイテストはエディタ実行 or Debugエクスポートで行うこと）。
3. コンソール（`Output`/`Debugger`パネル）を開いておき、想定外のエラー・警告が出ていないか随時確認する（[`godot-debug-tools.md`](../../../.claude/rules/godot-debug-tools.md)参照）。

## チェックリスト

### 1. 起動〜タイトル〜スロット選択〜新規ゲーム開始

- [ ] タイトル画面が表示され、「はじめから」「つづきから」「終了」ボタンが機能する
- [ ] 「はじめから」からスロット選択画面を経て新規ゲームが開始できる
- [ ] 起動〜新規ゲーム開始までの間、コンソールにエラーが出ていない

### 2. 庭（garden）

- [ ] 種の一覧から種を1つ選び、植え付けができる
- [ ] 「ターンを終了する」ボタンで庭の成長ターンが進む
- [ ] 植物が育ち、収穫できる状態になったら収穫できる
- [ ] 表示崩れ（テキストのはみ出し、ボタンの重なり等）がない

### 3. 調合（alchemy）

- [ ] レシピを選択できる
- [ ] 素材を投入枠に配置できる
- [ ] 「調合を実行する」ボタンで調合物ができる
- [ ] 「ターンを終了する」ボタンで納品〜ランク判定まで進む
- [ ] 表示崩れがない

### 4. ギルド納品（guild）

- [ ] ターン終了後、納品結果画面（GuildDeliveryScreen）が表示される
- [ ] 納品結果の内訳（貢献度・報酬）が読める
- [ ] 「続ける」で庭画面へ戻る

### 5. ランク進行（DebugPanelで高速に確認）

- [ ] DebugPanelの「次ランクへ」を連打し、G→F→E→D→C→B→A→Sまで全ランクを辿れる
- [ ] 各ランク到達時、画面上部のRankHud（ランク名・ノルマバー）が正しく更新される
- [ ] 末尾ランク（S）で「次ランクへ」を押しても何も起きない（クラッシュしない、ランクが変わらない）
- [ ] 途中、庭・調合の画面のロック状態や解禁レシピ表示に矛盾がない（例: 高ランクで解禁されるはずのレシピ・特性が反映される）

### 6. 昇格試験（DebugPanelでスキップしない）

- [ ] 通常フローで実際にノルマを消化し、昇格試験が開始することを最低1回確認する（`次ランクへ`はここでは使わない。試験画面自体の見た目・操作感の検証が目的のため）
- [ ] 試験中の残ターン表示・ノルマ表示が正しく更新される
- [ ] 試験に合格すると昇格し、工房強化画面へ自動遷移する
- [ ] （余裕があれば）試験に失敗した場合の挙動も確認する

### 7. 工房強化（workshop）

- [ ] DebugPanelの「G+1000」でゴールドを確保できる（画面上部のゴールド表示が即座に増える）
- [ ] 恒久強化を購入すると確認ダイアログが出て、確定すると反映される
- [ ] 消耗投資（確認ダイアログなしのもの）が購入でき、反映される
- [ ] ゴールド不足時は購入ボタンを押しても状態が変化しない
- [ ] 「閉じる」で元の画面（庭または調合）に正しく復帰する

### 8. セーブ/ロード・設定・一時停止メニュー

- [ ] プレイ中に一時停止メニューを開いても、閉じれば元の状態のままプレイを再開できる
- [ ] 設定画面（BGM/SE音量スライダー、ウィンドウモード）を開閉してもクラッシュしない（音声は現状no-opのため聞こえなくて正常）
- [ ] セーブ→タイトルに戻る→つづきからロードで、直前の状態（ゴールド・ランク・在庫）が復元される
