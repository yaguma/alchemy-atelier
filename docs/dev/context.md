## Coding Conventions

### Naming

| Target | Convention | Example |
|--------|-----------|---------|
| 変数・関数 | snake_case | `plant_seed()`, `_current_phase` |
| クラス（`class_name`） | PascalCase | `GameState`, `AlchemyScreen` |
| private（モジュール内限定）メンバ | `_`prefix | `_gold`, `_placed_material_ids` |
| 定数 | UPPER_SNAKE_CASE | `GARDEN_SLOT_COUNT`, `BUTTON_FONT_SIZE` |
| ファイル | snake_case | `quality_calculator.gd`, `alchemy_screen.gd` |
| シグナル | snake_case（過去形推奨） | `seed_planted(slot_index, seed_id)` |

### 型安全性

- 型注釈がほぼ全変数・関数シグネチャで徹底されている（`var _gold: int = 0`, `func get_state() -> Dictionary:`）
- ジェネリック型（`Array[MaterialInstance]`, `Dictionary[StringName, SeedMaster]`）を活用
- `Variant`は型ガード前提の一時変数に限定使用。無条件使用・安易な`as`キャストは規約違反

### Error Handling

- `push_error()` / `push_warning()` + 日本語メッセージ（例: `push_error("現在ランクのマスターデータが見つかりません: %s" % _current_rank_id)`）
- Domain層はResult型的な戻り値でエラーを統制し、UI層はエラーコード→メッセージ辞書（`ERROR_MESSAGES`）で表示に変換
- 例外機構（try/catch相当）はGDScriptに無いため使用しない

### Comment Style（信号機マーカー文化が定着）

- 🔵 確定・前工程指示、🟡 妥当な推測・暫定値、🔴 AI推論補完・重要な決定経緯、の3段階が全体で徹底されている
- 仕様参照（`FR-101`, `CON-xxx`等）を伴うコメントが多い
- 日本語コメントが主流

### Import / 依存の書き方

- `class_name`経由のグローバル参照が主流（`preload`+`const`での再宣言は`class_name`を隠してコンパイルエラーになるため禁止）
- `preload`は`.tscn`シーン・`assets/`（フォント・画像）参照、および`class_name`を持たない補助スクリプト（`tests/mocks/`等）に限定
- 機能間の直接参照は禁止。他Featureの`logic/*.gd`・`resources/*.gd`のみ参照可（`state/`・`ui/`は不可）。データ受け渡しは`GameState`（Autoload）経由に統一

## Additional Notes

- **アーキテクチャ**: Feature-Based Architecture + Functional Core, Imperative Shell（`logic/`=純粋static func、`autoload/`・`ui/`=副作用担当）。詳細は`.claude/rules/architecture.md`、設計原本は`docs/design/atelier-alchemy-core/architecture.md`
- **状態管理**: `GameState`（Autoload）が単一の情報源。`get_state()`は`duplicate(true)`でディープコピーを返す実装が必須（呼び出し元からの内部破壊防止）。EventBus相当はGodotネイティブの`signal`（専用Autoloadなし）
- **Bashコマンド運用ルール**: 1回のBash呼び出しで1コマンドのみ実行し、`&&`/`;`/`|`で連結しない（`.claude/rules/bash-commands.md`、CLAUDE.md）。依存コマンドのみ`&&`チェーン可
- **Git運用**: `git rebase`禁止（常に`git merge`）、`--force`系・`reset --hard`等の破壊的コマンドは慎重運用。コミットメッセージは`<type>: <subject>`（日本語、Conventional Commits準拠）。mainへのマージはPR経由必須
- **コミット前必須チェック**: GdUnit4全件 → gdlint → gdformat --checkの3点、全パス必須
- **PR運用**: `code-review`スキル・`pr-review-team`（7レビュアー体制）が利用可能。Critical指摘はマージ前に必ず修正
- **既知の制約**: BGM/SE音量設定はAudioBusLayout未整備のため現状no-op（音声再生機能自体が未実装）。`docs/tasks/atelier-alchemy-core/`は未作成のまま据え置き
- **デザイン**: 2026-09-19時点で全画面（title/garden/alchemy/guild/rank/workshop）と共通UI（RankHud/TabBar）がドット絵（ピクセルアート）技法に統一済み（`design-guide.md`）。水彩ファンタジースタイルは現状未使用（将来の設計原則として文書に残置のみ）。関連: `shared/ui/pixel_backdrop_applier.gd`, `shared/theme/button_style_applier.gd`、各機能の`*_backdrop.gd`（garden/alchemy/guild/rank/workshop）
