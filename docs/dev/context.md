## Coding Conventions

🔵 全て `.claude/rules/coding-style.md` および `architecture.md` に厳密な規約あり（要点のみ抜粋）。

### Naming

| Target | Convention | Example |
|--------|-----------|---------|
| 変数・関数 | snake_case | `material_list`, `calculate_reward` |
| クラス（`class_name`） | PascalCase | `MaterialCard`, `QualityCalculator` |
| シグナル | snake_case（過去形推奨） | `phase_changed`, `gold_changed` |
| 定数 | UPPER_SNAKE_CASE | `MAX_DECK_SIZE`, `GAME_BALANCE` |
| ファイル・ディレクトリ | snake_case | `material_card.gd`, `garden/` |
| privateメンバ | 先頭`_` | `_internal_state` |

### 型安全性

- 全変数・引数・戻り値に型注釈必須。`Variant`の無条件使用禁止（型ガード必須）。安易な`as`キャスト禁止。

### Functional Core, Imperative Shell

- `logic/*.gd`（`static func`, `Node`非継承）= 副作用なし・乱数は引数で受け取る
- `autoload/`, `ui/` = 副作用あり（I/O・状態変更・signal発行）
- Domain層システム同士は直接参照禁止。すべて`GameState`（Application層）が仲介する

### Error Handling / Logging

- `print()`を本番コードに残さない。デバッグ出力は`push_warning()`/`push_error()`またはデバッグフラグ経由
- `@ts-ignore`相当（`Variant`の無検証使用等）は原則禁止

### コメント

- 「なぜ」を説明する場合のみ記述。「何を」の説明・自明なコメント・コメントアウトされたコードは禁止
