# 画面設計書テンプレート

`docs/design/atelier-alchemy-core/ui-design/screens/garden.md`と同じ構成を使う。新規画面は
このテンプレートをそのままコピーして埋め、既存画面の演出追加は該当セクションだけ更新する。

未確定の項目には既存文書の慣例通り🟡（要確認・TBD）・🔴（矛盾や不具合の記録）・🔵（確定事項の補足）
の絵文字を付け、根拠不明な記述をしない。分からない箇所は空欄ではなく🟡TBDと明記する。

```markdown
# {画面名} 詳細設計

作成日: {YYYY-MM-DD}
準拠要件: [`../../../../spec/atelier-alchemy-core/requirements.md`](../../../../spec/atelier-alchemy-core/requirements.md) §{該当節}

## 基本情報

| 項目 | 値 |
|------|-----|
| 画面ID | SCR-{NNN} |
| 親画面 | {常駐タブか、遷移元画面か} |
| 子画面 | {この画面から開くモーダル・遷移先があれば} |

## ワイヤーフレーム

\`\`\`
┌─────────────────────────────────────────────┐
│ {RankHud等の常時表示要素}                      │
├─────────────────────────────────────────────┤

## アニメーション

| トリガー | アニメーション | 手法 | 時間 | イージング |
|----------|---------------|------|------|-----------|
| {例: 調合成功時} | {例: 素材が投入枠へ飛ぶ} | Tween | 0.3s | EASE_OUT |

「手法」列は必ず埋める（Tween/スプライトシート/パーティクルのいずれか）。既存画面の演出追加では
この表の🟡TBD行を実際に決めた内容へ差し替えるだけでよい。

```

## 新規画面の場合の追加作業

1. 上記テンプレートを`docs/design/atelier-alchemy-core/ui-design/screens/{screen}.md`として保存
2. `docs/design/atelier-alchemy-core/ui-design/overview.md`の画面一覧テーブルに1行追加
   （画面ID・画面名・説明・詳細ファイルへのリンク）
3. 画面遷移が発生するなら`overview.md`の`mermaid`遷移図にも遷移元/遷移先を追加

## 既存画面の演出追加の場合

対象ファイルの「アニメーション」表と、関係する「UI要素」「イベント」の説明文だけを更新する。
ファイル全体を書き直したり、他のセクションの既存の記述（🔴🔵の履歴コメント含む）を消したりしない。
